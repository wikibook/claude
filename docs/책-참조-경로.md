# 책 본문 ↔ 저장소 참조 경로

> 이 문서는 **원고(별도 프로젝트)에 삽입할 저장소 참조 표기 목록**입니다.
> 독자가 책을 읽다가 실습 파일, 폴더 구조, 프롬프트 원문을 바로 찾을 수 있도록
> 본문 해당 절 끝에 짧은 안내 문구를 넣는 용도입니다.
> 인쇄본에서 읽기 쉽도록 전체 URL 대신 짧은 경로로 표기합니다.

## 표기 형식

각 실습/절 끝에 팁 박스 또는 한 줄로 삽입합니다.

```
📦 보충 자료 → github.com/wikibook/claude · chapters/ch03-아티팩트-코드-없이-도구-만들기/
```

문구는 장마다 길게 반복하지 않고, 실제 파일이 필요한 절 끝에만 넣는 편이 좋습니다.
개념 설명만 있는 절은 `resources/` 문서로 연결하고, 실습 산출물이 있는 절은 `chapters/chNN-.../` 폴더로 연결합니다.

## 장별 폴더 구성 원칙

| 자료 유형 | 저장 위치 | 원칙 |
| --- | --- | --- |
| 책 실습 결과물 | `chapters/chNN-.../` | 독자가 바로 열거나 복사할 수 있는 정제본만 둡니다. |
| 프롬프트 원문 | 실습 폴더 안 `프롬프트.md` 또는 장 폴더의 예시 문서 | 책의 [IN]을 재현하되 내부 작업 메모는 넣지 않습니다. |
| 폴더 구조 예시 | 장 폴더 아래 템플릿 폴더 | `CLAUDE.md`, `README.md` 등 구조 자체가 학습 자료인 경우 폴더째 제공합니다. |
| 횡단 참고 자료 | `resources/`, `skills/`, `plugins/` | 여러 장에서 반복해서 참조하는 링크와 용어를 모읍니다. |

## 참고

- 저장소 최상위 주소: `github.com/wikibook/claude`
- 한국어 폴더명은 GitHub 웹에서 정상 표시됩니다. 인쇄본에는 위 짧은 경로 그대로 적으면 됩니다.
- 공개 전 실행 예제 확인은 [배포 전 검증 체크리스트](검증-체크리스트.md)에서 따로 관리합니다.
