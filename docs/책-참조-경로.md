# 책 본문 ↔ 저장소 참조 경로 (저자용 핸드오프)

> 이 문서는 **원고(별도 프로젝트)에 삽입할 저장소 참조 표기 목록**입니다.
> 저장소 자체에는 영향을 주지 않으며, 저자가 책 본문 해당 절 끝에 아래 표기를 넣는 용도입니다.
> 인쇄본에서 읽기 쉽도록 전체 URL 대신 짧은 경로로 표기합니다.

## 표기 형식

각 실습/절 끝에 팁 박스 또는 한 줄로 삽입합니다.

```
📦 보충 자료 → github.com/wikibook/claude · chapters/ch04-아티팩트/
```

## 배포 전 브라우저 스모크 테스트 (저자 확인용)

자동 검증으로 **구문·내부 링크·핵심 수치**는 확인했지만, 인터랙티브 동작은 브라우저에서 직접 확인이 필요합니다.

- [ ] `chapters/ch04-아티팩트/환율계산기/index.html` — 드롭다운 전환, 양방향 입력(100,000원 → $67.61 확인)
- [ ] `chapters/ch04-아티팩트/뽀모도로-타이머/index.html` — 시작/정지, 집중↔휴식 배경색 전환, 종료 알림음
- [ ] `chapters/ch04-아티팩트/매출-대시보드/index.html` — 막대 위 마우스 올릴 때 제품별 툴팁
- [ ] `chapters/ch08-클로드코드/포트폴리오/index.html` — 카드 3장, 링크 버튼 표시
- [ ] `chapters/ch08-클로드코드/프로젝트-보드/index.html` — 카드 추가, 드래그&드롭 이동, 새로고침 후 유지(로컬 저장)

> 검증 완료 항목: JS 구문, 내부 상대 링크, 환율·대시보드 골든 수치(책 [OUT] 일치).
> 미검증(브라우저 필요): 드래그&드롭, 알림음, 색 전환 등 인터랙션.
