# 배포 전 검증 체크리스트

저장소를 공개하거나 책 본문에서 경로를 안내하기 전에 저자가 확인할 항목입니다.

## 자동 검증

- [ ] `git diff --check` — Markdown 공백과 줄 끝 문제 확인
- [ ] Markdown 내부 상대 링크 검사 — 장별 README와 프롬프트 링크가 실제 파일을 가리키는지 확인
- [ ] `git ls-files '*.html' '*.css' '*.js'` — 실행형 웹 자료가 포함되지 않았는지 확인

## 내용 점검

- [ ] 루트 `README.md`의 장 제목이 원고의 `content/*.md` 제목과 일치한다.
- [ ] `docs/책-참조-경로.md`의 경로가 실제 공개 폴더와 일치한다.
- [ ] `resources/시작하기.md`의 설치 명령과 링크를 최신 공식 문서에서 다시 확인했다.
- [ ] Team, Enterprise, Slack, Claude Tag처럼 조건이 바뀌는 기능은 책 출간 직전에 다시 확인했다.
- [ ] 저장소에 HTML·CSS·JS 실행 파일이나 옵시디언 볼트 템플릿이 남아 있지 않다.
