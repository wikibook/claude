# 스킬 카탈로그

> 책 5장과 연결되는 보충 자료입니다.
> Claude Skills는 클로드에게 특정 작업 방식, 지식, 파일 처리 절차를 추가하는 기능입니다.

## 스킬을 살펴보는 순서

1. 먼저 공식 문서에서 Skills의 개념과 사용 방식을 확인합니다.
2. 공식 스킬 저장소에서 검증된 예시를 봅니다.
3. 필요한 경우 커뮤니티 스킬을 참고하되, 내용과 권한을 직접 확인한 뒤 사용합니다.

## 책에서 직접 만들 스킬 후보

아래 스킬은 5장 집필과 예제 정리 과정에서 확정될 예정입니다.

| 후보 | 용도 |
| --- | --- |
| 회의록 정리 스킬 | 회의 녹취나 메모를 의사결정, 할 일, 쟁점으로 정리합니다. |
| 직장인 글쓰기 스킬 | 이메일, 보고서, 제안서 초안을 업무 문체에 맞춰 다듬습니다. |

| 프롬프트 개선 스킬 | 막연한 요청을 실행 가능한 프롬프트로 바꾸는 절차를 제공합니다. |
