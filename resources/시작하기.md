## 가입과 로그인 (1장)

- **[클로드 웹 (claude.ai)](https://claude.ai)** — 가입하고 로그인해 바로 대화를 시작하는 곳. 여기서 출발합니다.

- **[데스크톱·모바일 앱 내려받기](https://claude.com/download)** — 이 책이 주로 다루는 데스크톱 앱을 여기서 설치하세요.
- **[도움말 (지원 센터)](https://support.claude.com)** — 기능·플랜·문제 해결을 확인하는 공식 허브(전 장).

## 클로드 코드 설치 (7장)

먼저 웹에서 가볍게 써 볼 수도 있고, 터미널에 설치해 본격적으로 쓸 수도 있습니다.

- **[웹에서 바로 쓰기](https://claude.ai/code)** — 설치 없이 브라우저에서 클로드 코드를 체험.
- **[클로드 코드 공식 문서](https://code.claude.com/docs)** — 설치·설정·활용 가이드.

터미널에 설치하려면 아래 명령을 실행합니다(책 7.2.3절).

```bash
# macOS · Linux
curl -fsSL https://claude.ai/install.sh | bash
```
```powershell
# Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex
```

> 설치 명령어는 버전에 따라 바뀔 수 있습니다. 실행 전 공식 문서에서 최신 명령어를 확인하세요.
