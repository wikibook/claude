# 용어집

> Claude 생태계와 AI 활용 문맥에서 자주 등장하는 용어를 쉬운 말로 정리했습니다.

| 한국어 | 영어 | 설명 |
| --- | --- | --- |
| 클로드 | Claude | Anthropic이 만든 AI 어시스턴트입니다. |
| 앤트로픽 | Anthropic | Claude를 개발하고 운영하는 AI 기업입니다. |
| 생성형 AI | Generative AI | 글, 이미지, 코드처럼 새 결과물을 만들어내는 AI입니다. |
| 대형 언어 모델 | Large Language Model, LLM | 많은 텍스트를 학습해 문장을 이해하고 생성하는 AI 모델입니다. |
| 모델 | Model | 사용자의 요청을 해석하고 답변을 만드는 AI의 핵심 엔진입니다. |
| 컨텍스트 | Context | AI가 답변할 때 참고하는 대화 내용, 파일, 지시사항의 범위입니다. |
| 프롬프트 | Prompt | 사용자가 AI에게 입력하는 요청이나 지시문입니다. |
| 시스템 지시 | System Instruction | AI가 전체 대화에서 지켜야 할 상위 규칙입니다. |
| 프로젝트 | Project | Claude에서 관련 대화, 파일, 지침을 묶어 관리하는 작업 공간입니다. |
| 아티팩트 | Artifact | Claude가 대화 옆에 별도 결과물로 보여주는 문서, 코드, 화면입니다. |
| 스킬 | Skill | Claude에게 특정 작업 절차나 전문 능력을 추가하는 패키지입니다. |
| 커넥터 | Connector | Claude가 Google Drive, Notion 같은 외부 서비스에 접근하도록 연결하는 기능입니다. |
| MCP | Model Context Protocol | AI와 외부 도구·데이터를 연결하기 위한 표준 규격입니다. |
| MCP 서버 | MCP Server | 파일, 웹, GitHub 같은 외부 기능을 AI에게 제공하는 연결 프로그램입니다. |
| Claude Code | Claude Code | 터미널과 코드 저장소에서 Claude를 활용하는 개발 도구입니다. |
| 플러그인 | Plugin | Claude Code에 특정 기능이나 서비스 연동을 추가하는 확장입니다. |
| Cowork | Cowork | Claude와 여러 도구를 엮어 실제 업무 흐름을 함께 처리하는 작업 방식입니다. |
| 루틴 | Routine | 반복되는 작업 절차를 저장해 다시 실행하기 쉽게 만든 구성입니다. |
| 워크플로우 | Workflow | 목표를 달성하기 위해 여러 단계와 도구를 연결한 작업 흐름입니다. |
| RAG | Retrieval-Augmented Generation | 외부 자료를 찾아 AI 답변에 반영하는 방식입니다. |
| 지식 저장소 | Knowledge Base | 문서, 메모, 참고 자료를 다시 찾기 쉽게 모아둔 공간입니다. |
| 옵시디언 | Obsidian | 마크다운 파일을 기반으로 개인 지식 저장소를 만드는 앱입니다. |
| 토큰 | Token | AI가 텍스트를 읽고 쓸 때 사용하는 작은 단위입니다. |
| 환각 | Hallucination | AI가 사실이 아닌 내용을 그럴듯하게 말하는 현상입니다. |
