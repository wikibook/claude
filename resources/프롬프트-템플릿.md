```

```

## 지식 관리 (옵시디언 · 9장)

**볼트 기본 구조 만들기** (9장 예제 9.1 · [볼트 템플릿](../chapters/ch09-옵시디언으로-나만의-지식-저장소-만들기/vault-template/))

```
이 폴더를 지식 저장소로 쓸 예정입니다. 기본 폴더 구조를 만들어주세요.

- sources/ : 원본 자료. 나중에 하위 폴더로 나눌 수 있게 비워두세요.
- wiki/ : AI가 쓰는 위키 페이지.
- daily/ : 매일의 메모.
- archive/ : 더 이상 참조하지 않는 자료.

각 폴더 안에 README.md를 만들고 용도를 한 줄로 적어주세요.
```

**새 소스 수집해 위키에 반영** (9장 예제 9.4 · [샘플 소스](../chapters/ch09-옵시디언으로-나만의-지식-저장소-만들기/vault-template/sources/articles/2027-04-10-ai-product-management.md))

```
새로 추가된 소스를 찾아 기존 위키를 업데이트하려고 합니다. 다음 순서대로 진행해주세요.

1. 새 소스를 요약합니다.
2. 주요 개념, 인물, 주장 등을 추출합니다.
3. 기존 위키에서 관련 페이지를 찾습니다.
4. 업데이트가 필요한 페이지를 제안합니다.
5. 새 페이지가 필요하면 생성 목록을 제안합니다.
6. index.md와 log.md 변경 사항도 함께 제안합니다.
7. 여기까지 제 검토를 받은 뒤 실제 파일을 수정합니다.
8. 작업이 끝나면 수정된 파일 목록과 변경 내용을 요약해서 보고합니다.
```
