# 프롬프트 템플릿 모음

> 각 항목 끝에 책의 어느 예제에서 왔는지 표시했습니다.

## 학습 · 새 분야 탐색

**눈높이에 맞춰 개념 설명받기** (5장 예제 5.6)

```
저는 <직무/배경>입니다. <배우려는 개념>이 무엇인지 제 눈높이에서
비유를 써서 쉽게 설명해주세요.
```

**4주 학습 계획 세우기** (5장 예제 5.7)

```
저는 <배경>입니다. <배우려는 분야>를 4주 안에 실무 수준으로 익히고 싶습니다.
지금 수준은 <현재 수준>이고, 하루 <시간> 투자 가능합니다. 4주 학습 계획을 만들어주세요.
```

**이해도 확인 퀴즈 받기** (5장 예제 5.8)

```
방금 <주제>를 배웠습니다. 얼마나 이해했는지 확인할 수 있게 퀴즈 5문제를 내주세요.
<직무> 실무 맥락에서 적용할 수 있는 문제로, 정답은 먼저 보여주지 말고 문제만 주세요.
```

```

이 파일들을 하나로 합쳐서 <결과파일명>.csv로 저장해주세요.
중복된 행은 제거하고, <기준> 기준으로 정렬해주세요. 병합 후 총 행 수도 알려주세요.
```

**이미지 일괄 크기 조정·이름 변경** (8장 예제 8.5)

```
파일 이름을 "<접두어>_001" 형식으로 순서대로 바꿔주세요.
원본 파일은 <백업폴더명> 폴더에 따로 보관해주세요.
```

## 지식 관리 (옵시디언 · 10장)

**볼트 기본 구조 만들기** (10장 예제 10.1 · [볼트 템플릿](../chapters/ch10-옵시디언/vault-template/))

```
이 폴더를 지식 저장소로 쓸 예정입니다. 기본 폴더 구조를 만들어주세요.

- sources/ : 원본 자료. 나중에 하위 폴더로 나눌 수 있게 비워두세요.
- wiki/ : AI가 쓰는 위키 페이지.
- daily/ : 매일의 메모.
- archive/ : 더 이상 참조하지 않는 자료.

각 폴더 안에 README.md를 만들고 용도를 한 줄로 적어주세요.
```

**새 소스 수집해 위키에 반영** (10장 예제 10.4)

```
sources/에 방금 추가된 파일을 찾아서 위키에 반영해주세요.
먼저 (1) 한 단락 요약, (2) 추출할 엔티티·개념·주장, (3) 업데이트할 기존 페이지,
(4) 새로 만들 페이지 목록을 보여주세요. 제가 확인한 다음에 편집을 시작하고,
끝나면 수정·생성한 파일 목록을 모두 보여주세요.
```
