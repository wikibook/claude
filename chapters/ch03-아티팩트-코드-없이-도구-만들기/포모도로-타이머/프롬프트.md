# 포모도로 타이머 — 사용한 프롬프트

『클로드 활용 입문서』 3.2.2절 예제 3.4~3.5의 [IN] 요청문입니다.

## 1단계 — 초기 요청 (예제 3.4)

```
포모도로 타이머를 만들어주세요. 기본 설정은 집중 25분, 휴식 5분입니다. 시작/정지/리셋 버튼이 있어야 하고, 타이머가 끝나면 소리로 알림을 주세요. 집중 시간과 휴식 시간은 제가 직접 수정할 수 있게 해주세요. 시간의 흐름이 느껴지도록 애니메이션도 넣어줬으면 좋겠습니다.
```

## 2단계 — 디자인 수정 (예제 3.5)

```
배경을 밝은 색으로 바꿔주세요. 집중 시간에는 빨간색 계열, 휴식 시간에는 초록색 계열로 배경이 바뀌면 좋겠습니다. 그리고 지금까지 완료한 포모도로 횟수를 토마토 아이콘과 같이 표시해주세요.
```

> 위 요청을 클로드 아티팩트에 붙여 넣으면 책과 같은 타이머가 만들어집니다.
> 알림음은 Web Audio로 만들 수 있어 별도 음원 파일이 필요 없습니다.
