# 포모도로 타이머 — 사용한 프롬프트

『클로드 활용 입문서』 3.2.2절에서 이 도구를 만들 때 보낸 요청입니다.

## 1단계 — 초기 요청 (예제 3.4)

```
포모도로 타이머를 만들어주세요. 기본 설정은 집중 25분, 휴식 5분입니다.
시작/정지/리셋 버튼이 있어야 하고, 타이머가 끝나면 소리로 알림을 주세요.
집중 시간과 휴식 시간은 제가 직접 수정할 수 있게 해주세요.
```

## 2단계 — 디자인 수정 (예제 3.5)

```
배경을 어두운 색으로 바꿔주세요. 집중 시간에는 빨간색 계열,
휴식 시간에는 초록색 계열로 배경이 바뀌면 좋겠습니다.
그리고 지금까지 완료한 포모도로 횟수도 표시해주세요.
```

> 같은 폴더의 `index.html`은 위 두 요청으로 완성되는 타이머를 같은 동작으로 재현한 결과입니다.
> 알림음은 Web Audio로 만들어 별도 음원 파일이 필요 없습니다.
