# 3장 아티팩트, 코드 없이 도구 만들기

> **책 3장** 독자를 위한 보충 자료입니다.
> 클로드 기능 변화에 맞춰 지속적으로 업데이트합니다.

## 이 장의 실습 자산

책 3.2절에서 클로드 아티팩트로 만든 세 가지 도구를, 같은 동작 그대로 **단일 HTML 파일**에 담았습니다.
각 폴더의 `index.html`을 브라우저로 열면 인터넷 연결 없이 바로 작동하고, 같은 폴더의 `프롬프트.md`에는
도구를 만들 때 쓴 요청([IN])이 단계별로 담겨 있어 직접 따라 만들어볼 수 있습니다.

#### 💳 구독료 계산기
서비스 이름과 요금을 한 줄씩 추가하면 월 합계와 연간 합계(월 × 12)가 바로 나오는 도구입니다.
항목마다 월간·연간 결제를 고를 수 있고, 연간 결제는 12로 나눠 월 비용으로 환산해 합계에 넣으며,
가장 비싼 구독은 👑로 강조합니다. "몇 개 안 되는데" 싶던 구독료를 1년 단위로 보면 감이 확 옵니다.
→ [`구독료-계산기/`](구독료-계산기/index.html) · 책 3.2.1절 예제 3.2~3.3, 그림 3.3~3.4

#### 🍅 뽀모도로 타이머
25분 집중 / 5분 휴식을 반복하는 시간 관리 타이머입니다. 집중·휴식 시간을 직접 조정할 수 있고,
끝나면 소리로 알리며, 집중은 붉은 톤·휴식은 초록 톤으로 배경이 서서히 바뀝니다. 완료한 뽀모도로
횟수도 토마토 아이콘으로 쌓입니다.
→ [`뽀모도로-타이머/`](뽀모도로-타이머/index.html) · 책 3.2.2절 예제 3.4~3.5, 그림 3.5~3.6

#### 📊 매출 대시보드
월별 매출을 막대·파이 차트로 보여주는 대시보드입니다. 막대에 마우스를 올리면 툴팁으로 정확한
수치가 뜹니다. 숫자 표 대신 그림으로 보면 흐름이 한눈에 들어온다는 것을 확인할 수 있습니다.
→ [`매출-대시보드/`](매출-대시보드/index.html) · 책 3.2.3절 예제 3.6~3.7, 그림 3.7~3.8

> 책 본문은 클로드에게 보낸 요청과 결과 설명·화면을 싣습니다(아티팩트의 전체 코드는 싣지 않습니다).
> 여기 파일은 책에서 설명한 동작·디자인에 맞춰 같은 결과가 나오도록 재현한 것입니다.

## 만든 아티팩트 공유하기

책 3.3절에서 다루는 세 가지 내보내기 방법입니다.

| 방법 | 설명 | 비고 |
| --- | --- | --- |
| 파일 다운로드 | 아티팩트 창에서 `.html`/`.tsx`로 저장 | 사내 시스템에 붙여 쓰기 |
| 링크 게시·공유 | Free·Pro·Max는 공개 게시, Team·Enterprise는 조직 내 공유 | 받는 사람이 브라우저에서 바로 실행 |
| 웹사이트 임베드 | 게시 후 `<iframe>` 코드로 블로그·위키에 삽입 | 허용 도메인 등록 필요 |

> **💡 팁: 공유 전에 확인하세요**
>
> 공개 링크는 URL을 아는 사람이라면 누구나 접근할 수 있어요. 매출 수치나 개인 정보가
> 아티팩트 안에 들어 있지는 않은지 먼저 확인하세요(책 3.3절).
