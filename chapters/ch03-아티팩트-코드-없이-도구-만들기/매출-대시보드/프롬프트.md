# 매출 대시보드 — 사용한 프롬프트

『클로드 활용 입문서』 3.2.3절에서 이 도구를 만들 때 보낸 요청입니다.

## 1단계 — 초기 요청 (예제 3.6)

```
아래 매출 데이터로 대시보드를 만들어주세요. 월별 매출 추이를 선 그래프로,
제품별 매출 비중을 파이 차트로 보여주고, 색상은 파란색 계열로 통일해주세요.

월, 제품A, 제품B, 제품C
1월, 1200, 850, 430
2월, 1350, 900, 510
3월, 1100, 780, 480
4월, 1480, 1020, 620
5월, 1600, 1150, 700
6월, 1750, 1200, 780
```

## 2단계 — 인터랙션 추가 (예제 3.7)

```
월별 추이를 선 그래프 대신 막대 그래프로 바꿔주세요.
그리고 각 달에 마우스를 올리면 제품별 세부 수치가 뜨면 좋겠습니다.
```

> 같은 폴더의 `index.html`은 위 두 요청으로 완성되는 대시보드(막대 그래프 + 툴팁 + 파이 차트)를
> 같은 동작으로 재현한 결과입니다. 막대에 마우스를 올리면 제품별 세부 수치가 보입니다.
