# 구독료 계산기 — 사용한 프롬프트

『클로드 활용 입문서』 3.2.1절에서 이 도구를 만들 때 클로드에게 보낸 요청입니다.

## 1단계 — 초기 요청 (예제 3.2)

```
매달 내는 구독 서비스 비용을 정리하는 계산기를 만들어주세요. 서비스 이름과 월 요금을 한 줄씩 추가하고 삭제할 수 있게 하고, 전체 월 합계와 연간 합계를 보여주세요. 깔끔하고 보기 쉬운 디자인으로요.
```

## 2단계 — 기능 추가 (예제 3.3)

```
연간으로 결제하는 서비스도 있습니다. 항목마다 월간·연간 결제를 고를 수 있게 하고, 연간 결제는 12로 나눠 월 비용으로 환산해서 합계에 넣어주세요. 그리고 가장 비싼 구독을 눈에 띄게 표시해주세요.
```

> 같은 폴더의 `index.html`은 위 두 요청으로 완성되는 도구를 같은 동작으로 재현한 결과입니다.
