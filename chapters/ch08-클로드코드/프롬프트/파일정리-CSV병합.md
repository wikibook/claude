# CSV 파일 병합 자동화 — 사용한 프롬프트

『클로드 활용 입문서』 8.4.3절(예제 8.4)에서 클로드 코드에게 보낸 요청입니다.
이 작업의 결과물은 코드가 아니라 정리된 데이터 파일(`merged_data.csv`)이므로,
저장소에는 따라 쓸 수 있는 프롬프트만 담았습니다. 터미널에서 `claude`를 실행한 뒤 그대로 입력하세요.

```
data 폴더 안에 CSV 파일이 12개 있습니다. 파일마다 날짜, 상품명, 판매량, 매출액 열이
있는데 내용이 조금씩 다릅니다. 이 파일들을 하나로 합쳐서 merged_data.csv로 저장해주세요.
중복된 행은 제거하고, 날짜 기준 오름차순으로 정렬해주세요.
```

> **💡 결과는 반드시 확인하세요(책 8.4.3절 팁)**
> 병합이 끝나면 결과 파일을 열어 행 수와 중복 제거가 의도대로인지 직접 확인하세요.
> 아예 처음부터 "병합 후 총 행 수를 알려주세요"를 요청에 넣으면 더 정확합니다(좋은 요청 습관 ②).
