# 개인 포트폴리오 페이지 — 사용한 프롬프트

『클로드 활용 입문서』 8.4.2절(예제 8.3)에서 클로드 코드에게 보낸 요청입니다.

## 1단계 — 초기 요청

```
개인 포트폴리오 페이지를 만들어주세요. 이름과 직함, 간단한 소개 문구가 상단에 들어가고,
주요 작업물 3건을 카드 형태로 보여주면 좋겠습니다. 깔끔하고 전문적인 느낌으로 부탁드립니다.

내 정보:
- 이름: 박지수 / 프리랜서 콘텐츠 디자이너
- 소개: "브랜드의 이야기를 시각으로 만드는 사람입니다"
- 작업물: 브랜드 로고 리디자인, 뉴스레터 템플릿, 인스타그램 피드 기획
```

## 2단계 — 수정 요청

```
배경색을 밝은 파란 계열로 바꿔주세요. 그리고 각 작업 카드에 링크 자리를 추가해주세요.
지금은 "#"으로 채워두어도 괜찮습니다.
```

> 같은 폴더의 `index.html`과 `style.css`는 위 두 요청으로 완성되는 페이지를 재현한 결과입니다.
> `index.html`을 더블클릭하면 브라우저에서 바로 열립니다.
