# 개인 프로젝트 추적 보드 — 사용한 프롬프트

『클로드 활용 입문서』 8.5.2절(예제 8.6), 8.5.3절(예제 8.7)에서 클로드 코드에게 보낸 요청입니다.

## 1단계 — 보드 만들기 (예제 8.6)

```
개인 프로젝트 추적용 간단한 웹 보드를 만들어주세요. 할 일을 카드로 추가할 수 있고,
카드마다 제목, 마감일, 메모를 입력할 수 있으면 좋겠습니다. 카드를 "할 일", "진행 중",
"완료" 세 열로 드래그해서 이동할 수 있으면 좋겠습니다. 내 컴퓨터에서 바로 쓸 수 있게
만들어주세요.
```

## 2단계 — 우선순위 색상 (예제 8.7)

```
카드 색상을 우선순위별로 다르게 적용해주세요.
긴급은 레드 테두리, 보통은 그린 테두리, 낮음은 그레이 테두리로요.
```

> 같은 폴더의 `index.html`·`style.css`·`app.js`는 위 요청으로 완성되는 칸반 보드를 재현한 결과입니다.
> 카드는 브라우저 로컬 저장소에 자동 저장되어, 인터넷 연결 없이도 내 컴퓨터에서 바로 쓸 수 있습니다.
