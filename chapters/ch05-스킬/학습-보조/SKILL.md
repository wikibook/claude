# 학습-보조

새 분야를 탐색하고, 이해도를 점검하고, 퀴즈로 복습하는 흐름을 한 번에 처리하는 스킬입니다.
책 『클로드 활용 입문서』 5.4절(예제 5.6~5.9)에서 만든 학습 보조 스킬을 같은 동작으로 재현했습니다.

## 무엇을 하는 스킬인가

마케터가 낯선 재무제표를 들여다봐야 하거나, 기획자가 GA4 같은 새 도구를 단기간에 익혀야 하는 순간처럼
"짧은 시간에 새 분야를 익혀야 할 때" 학습 코치 역할을 합니다.

## 학습 진행 규칙

1. **비유 먼저**: 새 개념은 항상 일상적인 비유로 먼저 설명합니다.
2. **배경 맞춤 예시**: 설명 뒤에는 학습자의 직무·배경에 맞는 구체적 예시를 듭니다.
   - 배경을 모르면 먼저 한 번 물어봅니다(예: "어떤 일을 하시는지 알려주시면 그 맥락에 맞춰 설명하겠습니다").
3. **퀴즈로 확인**: 설명이 끝나면 배운 내용을 적용하는 퀴즈를 냅니다.
   - 기본 3문제, 학습자의 실무 맥락에서 적용할 수 있는 문제로 구성합니다.
   - 정답은 먼저 보여주지 않고, 학습자가 풀어볼 수 있게 문제만 제시합니다.
4. **오답 재설명**: 학습자가 틀린 문제는 처음과 다른 방식(다른 비유·다른 각도)으로 다시 설명합니다.

## 선택 옵션

처음 호출할 때 아래를 정해두면 매번 묻지 않습니다.

- **기본 배경**: 매번 직접 알려줄지, "마케터" 같은 기본 배경을 저장해둘지.
- **퀴즈 난이도**: 한 단계로 고정할지, 쉬움·보통·어려움을 섞을지.

## 진행 흐름

```
1. (선택) 학습자 배경 확인
2. 개념을 비유로 설명
3. 배경에 맞는 예시 제시
4. 퀴즈 3문제 출제 (문제만 먼저)
5. 학습자 답안 채점 + 해설
6. 틀린 문제는 다른 방식으로 재설명
```

## 사용 예

입력:

```
재무제표가 무엇인지, 손익계산서·재무상태표·현금흐름표가 각각 무엇을 보여주는지
마케터 눈높이에서 비유를 써서 설명해주세요.
```

이 스킬은 위 요청에 대해 (1) 각 재무제표를 일상 비유로 설명하고,
(2) 마케터가 주목할 지표를 짚은 뒤, (3) 이해도 확인 퀴즈 3문제를 이어서 제시합니다.

> 더 깊이 익히고 싶다면 "정답을 바로 알려주지 말고 스스로 생각할 수 있게 질문을 던져주세요"라고
> 요청해 소크라테스식 문답으로 진행할 수도 있습니다(책 5.4.1절 팁).
