# 4장 아티팩트, 코드 없이 도구 만들기

> **책 4장** 독자를 위한 보충 자료입니다.
> 클로드 기능 변화에 맞춰 지속적으로 업데이트합니다.

## 이 장의 실습 자산

책 4.2절에서 클로드 아티팩트로 만든 세 가지 도구를, 같은 동작으로 단일 HTML 파일에 담았습니다.
각 폴더의 `index.html`을 브라우저로 열면 **인터넷 연결 없이 바로** 작동합니다.
같은 폴더의 `프롬프트.md`에는 책에서 도구를 만들 때 쓴 요청([IN])이 그대로 담겨 있어, 직접 따라 만들어볼 수 있습니다.

| 폴더 | 도구 | 책 연결 |
| --- | --- | --- |
| [`환율계산기/`](환율계산기/index.html) | 원화 ↔ 달러·엔화 양방향 환율 계산기 | 4.2.1절 예제 4.2~4.3, 그림 4.3 |
| [`뽀모도로-타이머/`](뽀모도로-타이머/index.html) | 집중/휴식 타이머(배경 전환·완료 횟수) | 4.2.2절 예제 4.4~4.5, 그림 4.4 |
| [`매출-대시보드/`](매출-대시보드/index.html) | 막대·파이 차트 매출 대시보드(툴팁) | 4.2.3절 예제 4.6~4.7, 그림 4.5 |

> 책 본문은 클로드에게 보낸 요청과 결과 설명·화면을 싣습니다(아티팩트의 전체 코드는 싣지 않습니다).
> 여기 파일은 책에서 설명한 동작·디자인에 맞춰 같은 결과가 나오도록 재현한 것입니다.

## 만든 아티팩트 공유하기

책 4.3절에서 다루는 세 가지 내보내기 방법입니다.

| 방법 | 설명 | 비고 |
| --- | --- | --- |
| 파일 다운로드 | 아티팩트 창에서 `.html`/`.tsx`로 저장 | 사내 시스템에 붙여 쓰기 |
| 링크 게시·공유 | Free·Pro·Max는 공개 게시, Team·Enterprise는 조직 내 공유 | 받는 사람이 브라우저에서 바로 실행 |
| 웹사이트 임베드 | 게시 후 `<iframe>` 코드로 블로그·위키에 삽입 | 허용 도메인 등록 필요 |

> **💡 팁: 공유 전에 확인하세요**
>
> 공개 링크는 URL을 아는 사람이라면 누구나 접근할 수 있어요. 매출 수치나 개인 정보가
> 아티팩트 안에 들어 있지는 않은지 먼저 확인하세요(책 4.3절).
