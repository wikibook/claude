# 환율 계산기 — 사용한 프롬프트

『클로드 활용 입문서』 4.2.1절에서 이 도구를 만들 때 클로드에게 보낸 요청입니다.
직접 따라 만들어보려면 클로드 대화창에 아래를 차례대로 입력하세요.

## 1단계 — 초기 요청 (예제 4.2)

```
원화(KRW)와 달러(USD)를 서로 변환하는 환율 계산기를 만들어주세요.
환율은 직접 입력할 수 있게 해주세요. 깔끔하고 사용하기 쉬운 디자인으로요.
```

## 2단계 — 기능 추가 (예제 4.3)

```
엔화(JPY) 변환도 추가해주세요. 그리고 통화를 선택하는 드롭다운 메뉴를 만들어서
원화 ↔ 달러, 원화 ↔ 엔화를 고를 수 있게 해주세요.
```

> 같은 폴더의 `index.html`은 위 두 요청으로 완성되는 도구를 같은 동작으로 재현한 결과입니다.
> 브라우저로 열면 인터넷 연결 없이 바로 쓸 수 있습니다.
