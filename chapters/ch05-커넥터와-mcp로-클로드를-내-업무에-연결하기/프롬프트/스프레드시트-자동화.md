# 스프레드시트 자동화 — 수식 · 오류 해결 · 데이터 정리 · 인사이트

『클로드 활용 입문서』 5.4절의 예제(5.3~5.6)입니다. 함수 문법을 몰라도 **하고 싶은 결과를
말로 설명**하면 클로드가 수식과 사용법을 알려줍니다. 구글 드라이브 커넥터를 연결했거나
스프레드시트 파일을 업로드한 뒤 아래 요청을 붙여 넣으세요.

> **💡 민감한 데이터는 가명 처리 후 전달하세요.** 고객 이름·전화번호·이메일 등 개인정보는
> "홍길동", "010-0000-0000" 같은 샘플로 바꿔 전달해도 클로드가 알려주는 수식은 똑같이 작동합니다.

---

## 1. 자연어로 수식 요청하기 (예제 5.3)

"직원 ID로 다른 표에서 부서명을 가져오고 싶다"처럼 목적만 말하면 됩니다.

```
엑셀에서 이런 작업을 하고 싶습니다. 시트1에는 [기준 열]과 [가져올 값]이 있고,
시트2에는 [기준 열]과 [다른 데이터]가 있습니다. 시트2에서 [기준 열]을 기준으로
시트1의 [가져올 값]을 가져와서 옆 열에 보여주고 싶습니다. 어떤 수식을 쓰면 되는지 알려주세요.
```

<details>
<summary>클로드의 응답 예시 보기 (VLOOKUP)</summary>

```
VLOOKUP 함수를 사용하면 됩니다. 시트2의 C2 셀에 아래 수식을 입력하세요.

=VLOOKUP(A2, Sheet1!A:B, 2, 0)

- A2: 찾으려는 값 / Sheet1!A:B: 찾을 범위 / 2: 가져올 열 번호 / 0: 정확히 일치
아래 행으로 복사하면 전체가 채워집니다. 단, 시트1의 A열(기준 값)이 반드시 첫 번째 열이어야
합니다. 중간 열에 있다면 XLOOKUP이 더 편리합니다.
```
</details>

## 2. 수식 오류 원인 파악하기 (예제 5.4)

`#N/A`, `#REF!`, `#VALUE!` 같은 오류 메시지와 해당 수식을 함께 전달하면 원인과 해결책을 짚어줍니다.

```
앞에서 알려준 [수식]을 입력했는데 일부 셀에서 [오류 메시지]가 납니다.
원인이 무엇인지 알려주세요.
```

<details>
<summary>클로드의 응답 예시 보기 (#N/A 원인 세 가지)</summary>

```
#N/A는 찾는 값이 기준 열에 없을 때 발생합니다. 주로 세 가지 이유입니다.
1. 값에 공백이 섞임 → =VLOOKUP(TRIM(A2), Sheet1!A:B, 2, 0)
2. 숫자와 텍스트 형식이 섞임 → 서식 통일 또는 TEXT 함수
3. 실제로 해당 값이 없음 → 오류 대신 빈칸: =IFERROR(VLOOKUP(...), "")
```
</details>

## 3. 지저분한 데이터 정리하기 (예제 5.5)

형식이 제각각인 데이터를 통일하는 방법을 요청합니다. 데이터를 붙여넣거나 파일을 업로드하세요.

```
[데이터 종류]를 정리해야 합니다. [열 이름] 열에 데이터가 아래처럼 뒤죽박죽입니다.

[형식이 제각각인 값 예시 몇 개]

이 데이터를 모두 [원하는 형식]으로 통일하려면 어떻게 하면 되는지 알려주세요.
```

<details>
<summary>클로드의 응답 예시 보기 (전화번호 형식 통일 · 구글 시트 정규식)</summary>

```
특수문자를 모두 제거한 뒤 숫자 11자리를 010-XXXX-XXXX 형식으로 재조합합니다.

=REGEXREPLACE(REGEXREPLACE(A2,"[^0-9]",""),"(\d{3})(\d{4})(\d{4})","$1-$2-$3")

데이터 양이 너무 많으면 파이썬이나 엑셀 파워 쿼리 같은 자동화도 이어서 요청해 보세요.
```
</details>

## 4. 데이터에서 인사이트 찾기 (예제 5.6)

단순 수치 정리를 넘어 숨은 패턴과 판단 거리를 짚게 합니다.

```
아래는 [데이터 설명]입니다. 이 데이터에서 주목할 만한 트렌드나 인사이트를 찾아주세요.

[월별/항목별 수치 붙여넣기]
```

> 클로드의 분석은 출발점입니다. 최종 판단은 업계 상황과 실제 업무 맥락을 아는 사람의 몫입니다.
