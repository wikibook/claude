# 커넥터 대표 질문 — 지메일 · 슬랙 · 노션

『클로드 활용 입문서』 5.2.2절에서 소개한, 각 서비스를 연결하자마자 바로 써볼 수 있는
"대표 질문"입니다. 무엇부터 연결할지 막막할 때, 서비스마다 대표 질문을 하나씩 정해 두면
커넥터의 쓸모를 금방 체감할 수 있습니다. 대괄호 안만 본인 상황으로 바꿔 붙여 넣으세요.

> 실제 업무 계정에 연결하기 전에 최소 권한·회사 보안 정책을 먼저 확인하세요.
> 클로드는 메일 답장 초안까지 써 주지만, **실제 발송은 사용자가 직접** 해야 합니다.

---

## 📧 지메일 — 밀린 메일 따라잡기

핵심은 요약이 아니라 **선별**입니다. 수백 통 더미에서 특정 프로젝트 스레드만 골라내는 일은
커넥터 없이는 사람이 하나하나 훑어야 합니다.

```
지난 2주 동안 받은 메일 중에서 [프로젝트명] 관련 스레드만 골라주세요.
각 스레드의 핵심 논의를 3줄로 요약하고, 제가 아직 답장하지 않은 건 따로 표시해주세요.
```

## 💬 슬랙 — 업무 대화 흐름 파악하기

채널을 통째로 요약하는 대신 업무에 직결되는 "결정"과 "책임 소재"만 걸러냅니다.

```
지난주 제가 휴가 중이었는데, [#채널명] 채널에서 결정된 사항만 뽑아서 알려주세요.
중요한 논쟁이 있었는지, 누가 어떤 액션 아이템을 가져갔는지도 같이 정리해주세요.
```

## 📓 노션 — 업무 지식 검색하고 빈 곳 찾기

문서 내용을 묻는 데서 그치지 않고, 기존 문서의 부족한 부분까지 짚게 하는 요청입니다.

```
노션에 있는 "[문서 제목]" 페이지를 읽어 주세요. [독자 관점]에서
"이 설명만으로는 뭘 해야 할지 모르겠다"고 느낄 만한 부분이 있으면
구체적인 문장과 함께 짚어주세요.
```

## 서비스별로 이런 질문이 잘 통합니다 (표 5.1)

| 서비스 | 대표 활용 질문 |
| --- | --- |
| 구글 드라이브 | 어느 폴더에 있는지 모르는 자료를 클로드가 직접 찾아오게 하기 |
| 지메일 | 지난 2주간 받은 메일에서 특정 프로젝트 스레드만 골라 요약 |
| 슬랙 | 내가 못 본 채널의 결정 사항과 액션 아이템만 추출 |
| 노션 | 사내 문서를 기준으로 답을 구하거나 문서의 빈 곳 점검 |
| 마이크로소프트 365 | 팀즈 대화·아웃룩 메일·원드라이브 문서를 한 번에 검색·분석(읽기 전용) |
| 아사나·리니어 | 이번 주 내가 담당한 이슈 목록과 현재 진행 상태 요약 |
| 피그마 | 디자인 파일의 변경 맥락과 디자이너가 남긴 코멘트 파악 |

> 그대로 쓸 수 있습니다. 마이크로소프트 365 커넥터는 검색·분석 중심의 읽기 전용으로 동작하니,
> 문서 편집·메일 발송은 직접 해야 한다는 점을 기억하세요.
