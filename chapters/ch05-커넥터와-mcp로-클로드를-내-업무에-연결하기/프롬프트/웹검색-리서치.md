# 웹 검색으로 리서치하기

『클로드 활용 입문서』 5.5절의 예제(5.7~5.8)입니다. 대화 입력창의 도구 메뉴에서
**웹 검색(Web search)** 토글을 켜면, 클로드가 최신 정보가 필요할 때 자동으로 웹을 검색하고
답변에 출처 링크를 함께 달아 줍니다. 시장 조사·경쟁사 모니터링·뉴스 정리로 바로 이어집니다.

---

## 1. 최신 시장 동향 조사 (예제 5.7)

원하는 항목을 목록으로 지정하고, **출처를 함께 요청**하는 것이 핵심입니다.

```
[시장/분야]의 최신 동향을 조사해주세요. 특히 다음 내용을 포함해주세요.

- 시장 규모와 성장 현황 (최신 데이터)
- 주요 플랫폼과 커뮤니티의 최근 움직임
- 주목받는 신규 서비스나 트렌드
- 출처도 함께 알려주세요
```

## 2. 관심 주제의 최근 뉴스 정리 (예제 5.8)

기간과 출력 형식(개수·표·목록)을 지정하면 원하는 모양으로 정리됩니다.

```
최근 [기간]간 [주제] 관련 뉴스를 검색해서 정리해주세요.
[관심 포인트 — 예: 신규 서비스 출시, 이용자 동향, 콘텐츠 트렌드]를 중심으로
[개수]개 항목으로 요약해주세요.
```

> **💡 팁:** 답변에서 더 궁금한 내용이 있으면 "방금 답변에서 언급한 ○○를 더 자세히 조사해주세요"처럼
> 꼬리를 물며 이어 질문하세요. 한 번에 끝내기보다 대화를 이어가며 파고드는 편이 결과가 낫습니다.

## 웹 검색 활용 시나리오와 팁 (표 5.2)

| 활용 시나리오 | 프롬프트 팁 | 주의사항 |
| --- | --- | --- |
| 시장 규모·성장률 조사 | 기간과 지역을 명시 ("최근 1년 국내") | 수치는 반드시 출처 원문 확인 |
| 경쟁사 최신 동향 | "최근 3개월 기준"처럼 기간 지정 | 홍보성 자료와 객관적 보도 구분 |
| 업계 뉴스 요약 | 뉴스 개수와 출력 형식(표·목록) 지정 | 빠르게 변하는 뉴스는 시점 확인 |
| 제도·법령 변경 확인 | "최근 개정" 또는 시행일 명시 | 국가 법령 데이터베이스 등 공식 출처 확인 |
| 기술 트렌드 파악 | 관심 분야와 기간을 좁혀서 요청 | 출처 신뢰도 확인(공식 기관·매체 우선) |

> **웹 검색 vs 연구 기능(책 5.5.4절).** 웹 검색은 몇 초 안에 답하는 "빠른 확인",
> 연구(Research) 기능은 수십 개 출처를 종합해 몇 분에 걸쳐 보고서를 내놓는 "깊은 조사"입니다.
> "경쟁사 세 곳의 최근 1년 전략을 비교해 시사점을 정리해 주세요"처럼 여러 갈래 조사가 필요하면 연구 기능을 쓰세요.
