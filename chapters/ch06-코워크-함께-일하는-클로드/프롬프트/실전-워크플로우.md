# 코워크 실전 워크플로우

책 6.3절의 실전 워크플로우 예시입니다. 하나의 요청으로 여러 자료를 읽고, 정리하고, 결과 파일까지 만들도록 맡기는 방식입니다. 대괄호 안만 본인 상황으로 바꿔 쓰세요.

> 아래 다섯 가지는 책 예제 6.7~6.11을 **본인 업무에 맞게 일반화한 템플릿**입니다.
> 책과 똑같은 요청문을 그대로 쓰고 싶다면 [`통합-파일-분석.md`](통합-파일-분석.md) · [`미팅-브리핑-자동-생성.md`](미팅-브리핑-자동-생성.md) · [`분기-보고서-자동화.md`](분기-보고서-자동화.md) · [`콘텐츠-대량-제작.md`](콘텐츠-대량-제작.md) · [`리서치-종합-보고서.md`](리서치-종합-보고서.md)를 참고하세요.

> 처음에는 실행 전 확인 모드에서 시작하세요. 파일 삭제, 외부 발송, 권한 변경은 항상 별도 승인을 요구하는 편이 안전합니다.

## 여러 형식의 파일 통합 분석

```
"[폴더 경로]" 폴더에 있는 파일들을 분석해서 핵심 내용을 하나로 정리해주세요.

- PDF 파일: 주요 수치와 결론 요약
- 엑셀 파일: 핵심 KPI 표로 정리
- 이미지 파일: 텍스트로 변환해서 포함

분석 결과를 "[결과파일명].docx"로 같은 폴더에 저장해주세요.
```

## 미팅 전 브리핑 자동 생성

```
30분 뒤에 [상대]와 미팅이 있습니다. 준비를 도와주세요.

1. 지메일에서 "[키워드]" 관련 최근 [기간] 이메일 스레드 찾기
2. 구글 드라이브의 "[폴더 경로]"에 있는 가장 최근 파일 읽기
3. 웹에서 [상대 회사/서비스]의 최근 [기간] 뉴스나 공지 찾기

세 내용을 합쳐서 A4 1쪽 분량의 미팅 브리핑을 만들어주세요.
파일명은 "[이름]_미팅브리핑_오늘날짜.docx"로 저장해주세요.
```

## 반복 보고서 자동화

```
구글 드라이브의 "[폴더 경로]"에 있는 팀별 엑셀 파일들을 분석해서 분기 실적 보고서를 만들어주세요.

보고서 형식:
- Word 파일, A4 3~4쪽
- 구성: 전체 요약 → 팀별 상세 실적 → 주요 이슈 및 다음 분기 계획
- Excel 요약표도 함께 만들기

완성되면 "[저장 폴더]"에 저장해주세요.
```

## 콘텐츠 한 달치 미리 만들기

```
[기간] 분량의 콘텐츠를 만들어주세요. 브랜드 정보는 프로젝트에 등록된 "[브랜드가이드라인.pdf]"를 참조하면 좋겠습니다.

필요한 것:
1. 콘텐츠 캘린더
2. 블로그 포스트 초안 [편수]편
3. 각 블로그 포스트에 대응하는 인스타그램 캡션

완성된 파일은 "[저장 폴더]"에 저장해주세요.
```

## 흩어진 정보에서 인사이트 찾기

```
[대상]에 대한 경쟁사 분석 보고서를 만들어주세요.

1. 웹에서 [대상]의 최근 [기간] 뉴스와 공시 자료 수집
2. 로컬 폴더 "[폴더 경로]"에 있는 기존 자료 참조
3. 두 정보를 종합해 SWOT 분석 포함 보고서 작성

보고서 형식: Word 파일, A4 3쪽 이내, 오늘 날짜로 파일명 설정
```

큰 작업은 한 번에 맡기기 전에 결과 파일명, 저장 위치, 확인이 필요한 행동을 명시하면 되돌리기 쉽습니다.
