# 코워크 실전 워크플로우 — 5가지 + 플러그인 캠페인

『클로드 활용 입문서』 6.3절의 다섯 가지 실전 워크플로우(예제 6.7~6.11)와, 6.2절의 마케팅
플러그인 예제(6.2)입니다. 모두 **하나의 요청으로 처음부터 끝까지** 처리하는 방식이라, 코워크에
그대로 붙여 넣고 대괄호만 본인 상황으로 바꾸면 됩니다.

> 코워크는 기본적으로 "작업 전 확인(Ask before acting)" 모드로 동작해, 실행 전에 "진행할까요?"라고
> 계획을 먼저 보여줍니다. 익숙해지면 "확인 없이 실행"으로 속도를 높이되, **파일 영구 삭제는 항상
> 별도 승인**을 요구합니다. 개인정보가 담긴 파일은 가명 처리 후 넘기는 것이 안전합니다.

---

## 1. 여러 형식의 파일을 통합 분석 (예제 6.7)

PDF·엑셀·이미지가 섞인 폴더를 한 문서로 정리합니다.

```
"[폴더 경로]" 폴더에 있는 파일들을 분석해서 핵심 내용을 하나로 정리해주세요.

- PDF 파일: 주요 수치와 결론 요약
- 엑셀 파일: 핵심 KPI 표로 정리
- 이미지 파일(화이트보드 사진 등): 텍스트로 변환해서 포함

분석 결과를 "[결과파일명].docx"로 같은 폴더에 저장해주세요.
```
> 표·차트가 많은 PDF는 "3페이지 표의 수치를 CSV로 변환해주세요"처럼 위치·형식을 지정하면 더 정확합니다.

## 2. 미팅 전 브리핑 자동 생성 (예제 6.8)

**코워크를 처음 익힐 때 가장 먼저 권하는 워크플로우입니다.** 거의 매일 반복되고, 읽기 위주라
안전하며, 여러 커넥터를 한 번에 쓰는 흐름을 자연스럽게 익힐 수 있습니다.

```
30분 뒤에 [상대]와 미팅이 있습니다. 준비를 도와주세요.

1. 지메일에서 "[키워드]" 관련 최근 [기간] 이메일 스레드를 찾아 주요 내용을 정리하기
2. 구글 드라이브의 "[폴더 경로]"에 있는 가장 최근 파일을 읽기
3. 웹에서 [상대 회사/서비스]의 최근 [기간] 뉴스나 공지를 찾기

세 내용을 합쳐서 A4 1쪽 분량의 미팅 브리핑을 만들어주세요.
파일명은 "[이름]_미팅브리핑_오늘날짜.docx"로 바탕화면에 저장해주세요.
```

## 3. 반복 보고서 자동화 (예제 6.9)

팀별 엑셀 파일을 모아 분기 보고서를 만듭니다. 한 번 설정하면 다음 분기엔 예약 작업에 등록해 자동 실행할 수 있습니다.

```
구글 드라이브의 "[폴더 경로]"에 있는 팀별 엑셀 파일들을 분석해서 분기 실적 보고서를 만들어주세요.

보고서 형식:
- Word 파일 (A4, 3~4쪽)
- 구성: 전체 요약 → 팀별 상세 실적 → 주요 이슈 및 다음 분기 계획
- Excel 요약표도 함께 만들어주세요 (팀별 핵심 KPI 비교)

완성되면 "[저장 폴더]"에 저장해주세요.
```
> 여러 파일을 다룰 때 코워크는 서브 에이전트를 자동으로 띄워 병렬 분석합니다(사용자가 설정할 필요 없음).

## 4. 콘텐츠 한 달치 미리 만들기 (예제 6.10)

브랜드 가이드라인을 프로젝트에 등록해 두면 톤을 지킨 초안이 한 번에 나옵니다.

```
[기간] 분량의 콘텐츠를 만들어주세요. 브랜드 정보는 프로젝트에 등록된 "[브랜드가이드라인.pdf]"를 참조하면 좋겠습니다.

필요한 것
1. 콘텐츠 캘린더 ([주기] 기준) - Excel로 저장
2. 블로그 포스트 초안 [편수]편 (각 800~1000자) - 각각 Word 파일로 저장
3. 각 블로그 포스트에 대응하는 인스타그램 캡션 - 블로그 파일 하단에 함께 작성

완성된 파일은 "[저장 폴더]"에 저장해주세요.
```

## 5. 흩어진 정보에서 인사이트 찾기 (예제 6.11)

형식이 제각각인 자료를 그대로 던져도 패턴을 뽑아냅니다("garbage in, treasure out").

```
[대상]에 대한 경쟁사 분석 보고서를 만들어주세요.

1. 웹에서 [대상]의 최근 [기간] 뉴스와 공시 자료를 수집하기
2. 로컬 폴더 "[폴더 경로]"에 있는 기존 자료도 함께 참조하기
3. 두 정보를 종합해서 SWOT 분석 포함 보고서를 만들기

보고서 형식: Word 파일, A4 3쪽 이내, 오늘 날짜로 파일명 설정
```

## 보너스 — 플러그인으로 캠페인 브리프 (예제 6.2)

마케팅 플러그인을 설치하면 `/campaign-plan` 명령어로 캠페인 브리프를 만들 수 있습니다.
명령어를 몰라도 "이번 신제품 출시 캠페인 기획서 만들어주세요"처럼 자연어로 요청하면 자동 적용됩니다.

```
/campaign-plan [캠페인 목적]을 위한 콘텐츠 캘린더를 구성해줘요.
[런칭 시점]에 런칭이고, [대상 청중]을 대상으로 해요.
```
> 플러그인은 많이 설치할수록 좋은 게 아닙니다. 지금 하는 일에 바로 도움이 되는 하나로 시작하세요.
> 플러그인 관리 화면의 **사용자 지정** 버튼으로 브랜드 가이드라인·선호 형식을 등록해 둘 수 있습니다.
