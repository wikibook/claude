# 예제 6.10 콘텐츠 대량 제작 - 캘린더 + 블로그 초안

책 6장 예제의 [IN] 요청문입니다.

```
5월 한 달 분량의 콘텐츠를 만들어주세요. 브랜드 정보는 프로젝트에 등록된 "브랜드가이드라인.pdf"를 참조하면 좋겠습니다.

필요한 것
1. 5월 콘텐츠 캘린더 (4주, 주 3회 게시 기준) - Excel로 저장
2. 블로그 포스트 초안 4편 (각 800~1000자) - 각각 Word 파일로 저장
3. 각 블로그 포스트에 대응하는 인스타그램 캡션 - 블로그 파일 하단에 함께 작성

완성된 파일은 "콘텐츠/5월" 폴더에 저장해주세요.
```
