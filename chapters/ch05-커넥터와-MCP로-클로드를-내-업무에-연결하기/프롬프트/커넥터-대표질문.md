# 커넥터 대표 질문

책 5.2.2절에서 소개한, 각 서비스를 연결하자마자 바로 써 볼 수 있는 질문입니다.
무엇부터 연결할지 막막할 때는 서비스마다 대표 질문 하나로 쓸모를 확인해 보세요.

> 아래 「구글 드라이브 — 책 예제」의 예제 5.1·5.2는 책 원문 그대로이고,
> 지메일·슬랙·노션 질문은 같은 방식을 본인 업무에 맞게 바꿔 쓰도록 일반화한 것입니다.
> 5장 예제 전체는 [`예제-프롬프트.md`](예제-프롬프트.md)에 모아 두었습니다.

> 실제 업무 계정에 연결하기 전에는 최소 권한과 회사 보안 정책을 먼저 확인하세요.
> 클로드가 답장 초안까지 써 주더라도 실제 발송은 사용자가 직접 확인해야 합니다.

## 지메일

```
지난 2주 동안 받은 메일 중에서 [프로젝트명] 관련 스레드만 골라주세요.
각 스레드의 핵심 논의를 3줄로 요약하고, 제가 아직 답장하지 않은 건 따로 표시해주세요.
```

## 슬랙

```
지난주 제가 휴가 중이었는데, [#채널명] 채널에서 결정된 사항만 뽑아서 알려주세요.
중요한 논쟁이 있었는지, 누가 어떤 액션 아이템을 가져갔는지도 같이 정리해주세요.
```

## 노션

```
노션에 있는 "[문서 제목]" 페이지를 읽어 주세요. [독자 관점]에서
"이 설명만으로는 뭘 해야 할지 모르겠다"고 느낄 만한 부분이 있으면
구체적인 문장과 함께 짚어주세요.
```


## 구글 드라이브 — 책 예제

### 예제 5.1 여러 문서에 걸친 모순 찾기

```
내 구글 드라이브의 "2027 분기 보고서" 폴더에서 1~3분기 보고서 세 건을 읽어 주세요. 그리고 같은 폴더의 "2027 연간 전략 방향" 파일과 비교해서, 분기 실적이 연초 전략과 어긋나는 지점이 있으면 알려주세요.
```

### 예제 5.2 내가 위치를 모르는 자료 찾아오기

```
A사와의 계약 관련 문서가 드라이브 어딘가에 있을 것 같습니다. 폴더는 기억나지 않습니다. 지난 3년치 A사 관련 계약서와 수정 조항들을 찾아서 시간 순으로 정리해주세요. 각 문서가 어떤 폴더에 있는지도 같이 알려주세요.
```

## 서비스별 질문 설계

| 서비스 | 대표 활용 질문 |
| --- | --- |
| 구글 드라이브 | 어느 폴더에 있는지 모르는 자료를 클로드가 직접 찾아오게 하기 |
| 지메일 | 최근 메일에서 특정 프로젝트 스레드만 골라 요약 |
| 슬랙 | 못 본 채널의 결정 사항과 액션 아이템 추출 |
| 노션 | 사내 문서를 기준으로 답을 구하거나 문서의 빈 곳 점검 |
| 마이크로소프트 365 | 팀즈 대화, 아웃룩 메일, 원드라이브 문서를 함께 검색·분석 |
| 아사나·리니어 | 이번 주 담당 이슈 목록과 현재 진행 상태 요약 |
| 피그마 | 디자인 파일의 변경 맥락과 디자이너 코멘트 파악 |

커넥터 질문은 "전체를 요약해줘"보다 "결정 사항", "미답장", "담당자", "확인 필요"처럼
걸러낼 기준을 함께 주는 편이 좋습니다.
