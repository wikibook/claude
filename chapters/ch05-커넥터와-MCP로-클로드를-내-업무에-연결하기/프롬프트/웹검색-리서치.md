# 웹 검색으로 리서치하기

책 5.5절의 예제입니다. 웹 검색을 켜면 클로드가 최신 정보가 필요할 때 웹을 검색하고 답변에 출처 링크를 함께 달아 줍니다. 시장 조사, 경쟁사 모니터링, 뉴스 정리에 바로 쓸 수 있습니다.

> 아래 요청문은 책 예제를 본인 업무에 맞게 바꿔 쓸 수 있도록 일반화한 것입니다.
> 책과 똑같은 요청문은 [`예제-프롬프트.md`](예제-프롬프트.md)에 원문 그대로 담았습니다.

## 최신 시장 동향 조사

```
[시장/분야]의 최신 동향을 조사해주세요. 특히 다음 내용을 포함해주세요.

- 시장 규모와 성장 현황
- 주요 플랫폼과 커뮤니티의 최근 움직임
- 주목받는 신규 서비스나 트렌드
- 출처와 날짜
```

## 최근 뉴스 정리

```
최근 [기간]간 [주제] 관련 뉴스를 검색해서 정리해주세요.
[관심 포인트]를 중심으로 [개수]개 항목으로 요약해주세요.
각 항목에는 출처, 날짜, 왜 중요한지를 함께 적어주세요.
```

## 검색 결과를 더 깊게 파고들기

```
방금 정리한 내용 중 [항목]을 더 자세히 조사해주세요.
공식 발표, 신뢰할 수 있는 보도, 커뮤니티 반응을 나눠서 정리하고
서로 충돌하는 내용이 있으면 따로 표시해주세요.
```

| 활용 시나리오 | 프롬프트 팁 | 주의사항 |
| --- | --- | --- |
| 시장 규모·성장률 조사 | 기간과 지역을 명시 | 수치는 원문 확인 |
| 경쟁사 최신 동향 | 최근 3개월처럼 기간 지정 | 홍보성 자료와 보도 구분 |
| 업계 뉴스 요약 | 뉴스 개수와 출력 형식 지정 | 시점 확인 |
| 제도·법령 변경 확인 | 시행일과 국가를 명시 | 공식 출처 우선 |
| 기술 트렌드 파악 | 관심 분야와 기간을 좁힘 | 출처 신뢰도 확인 |
