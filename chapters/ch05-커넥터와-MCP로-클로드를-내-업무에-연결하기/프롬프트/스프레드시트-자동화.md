# 스프레드시트 자동화

책 5.4절의 예제입니다. 함수 문법을 몰라도 하고 싶은 결과를 말로 설명하면
클로드가 수식과 사용법을 제안합니다. 구글 드라이브 커넥터를 연결했거나
스프레드시트 파일을 업로드한 뒤 아래 요청을 붙여 넣으세요.

> 아래 요청문은 책 예제를 본인 업무에 맞게 바꿔 쓸 수 있도록 일반화한 것입니다.
> 책과 똑같은 요청문은 [`예제-프롬프트.md`](예제-프롬프트.md)에 원문 그대로 담았습니다.

> 고객 이름, 전화번호, 이메일 등 민감한 데이터는 샘플 값으로 바꿔 전달해도 수식 설명은 그대로 쓸 수 있습니다.

## 자연어로 수식 요청하기

```
엑셀에서 이런 작업을 하고 싶습니다. 시트1에는 [기준 열]과 [가져올 값]이 있고,
시트2에는 [기준 열]과 [다른 데이터]가 있습니다. 시트2에서 [기준 열]을 기준으로
시트1의 [가져올 값]을 가져와서 옆 열에 보여주고 싶습니다. 어떤 수식을 쓰면 되는지 알려주세요.
```

## 수식 오류 원인 파악하기

```
앞에서 알려준 [수식]을 입력했는데 일부 셀에서 [오류 메시지]가 납니다.
원인이 무엇인지 알려주세요. 가능한 원인을 우선순위별로 나누고, 바로 시도할 수정 수식도 제안해주세요.
```

## 지저분한 데이터 정리하기

```
[데이터 종류]를 정리해야 합니다. [열 이름] 열에 데이터가 아래처럼 뒤죽박죽입니다.

[형식이 제각각인 값 예시 몇 개]

이 데이터를 모두 [원하는 형식]으로 통일하려면 어떻게 하면 되는지 알려주세요.
엑셀 수식, 구글 시트 수식, 수작업 확인이 필요한 경우를 나눠 설명해주세요.
```

## 데이터에서 인사이트 찾기

```
아래는 [데이터 설명]입니다. 이 데이터에서 주목할 만한 트렌드나 인사이트를 찾아주세요.

[월별/항목별 수치 붙여넣기]

결론을 먼저 쓰고, 근거가 되는 수치를 표로 정리한 뒤, 추가로 확인해야 할 질문 3개를 제안해주세요.
```

클로드의 분석은 출발점입니다. 최종 판단은 원본 데이터와 업무 맥락을 아는 사람이 확인해야 합니다.
