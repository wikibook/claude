# 5장 예제 프롬프트

> 책 5장 예제 5.1~5.9의 [IN] 요청문입니다. 그대로 복사해 사용하세요.
> 폴더 이름·파일 이름은 책 실습 기준이므로, 본인 드라이브 구성에 맞게 바꿔 쓰면 됩니다.
> 같은 폴더의 다른 파일은 이 예제를 본인 업무에 맞게 일반화한 템플릿입니다.

## 예제 5.1 여러 문서에 걸친 모순 찾기

```
내 구글 드라이브의 "2027 분기 보고서" 폴더에서 1~3분기 보고서 세 건을 읽어 주세요. 그리고 같은 폴더의 "2027 연간 전략 방향" 파일과 비교해서, 분기 실적이 연초 전략과 어긋나는 지점이 있으면 알려주세요.
```

## 예제 5.2 내가 위치를 모르는 자료 찾아오기

```
A사와의 계약 관련 문서가 드라이브 어딘가에 있을 것 같습니다. 폴더는 기억나지 않습니다. 지난 3년치 A사 관련 계약서와 수정 조항들을 찾아서 시간 순으로 정리해주세요. 각 문서가 어떤 폴더에 있는지도 같이 알려주세요.
```

## 예제 5.3 나챗방으로 기업 연구 요약 내역 보내기

```
Anthropic 최근 연구를 확인해서 요약해서 나챗방으로 보내줘요.
```

## 예제 5.4 지역과 기간을 정해 공연 조회하기

```
오늘 날짜를 기준으로 이번 주말에 서울 종로구에서 볼 수 있는 연극 3편을 찾아주세요. 공연명, 공연 기간, 장소, 관람료, 예매 링크를 표로 정리하고, 각 공연을 한 문장으로 소개해주세요.
```

## 예제 5.5 구글 드라이브의 기준 시트 확인하기

```
내 구글 드라이브에서 "상품 마스터"라는 이름의 구글 시트 파일을 찾아 읽어 주세요. 그리고 다음 내용을 확인해 주세요.

1. 어떤 열이 있는지
2. 상품 코드가 중복된 행이 있는지
3. 상품 코드, 상품명, 상품군, 정상 가격에 빈칸이 있는지
4. 상품 코드를 기준으로 주문 내역 CSV와 연결할 수 있는 상태인지

파일은 수정하지 말고 확인 결과만 알려주세요.
```

## 예제 5.6 로컬 CSV와 구글 시트 결합하기

```
내 구글 드라이브의 "상품 마스터" 시트와 방금 업로드한 '2027_06_주문내역.csv'를 함께 사용해 주세요. 다음 순서로 처리해 주세요.

1. CSV의 열 이름과 데이터 형식을 먼저 확인합니다.
2. 주문일을 YYYY-MM-DD 형식으로 통일합니다.
3. 주문번호가 중복된 행을 찾습니다.
4. 취소된 주문은 매출 집계에서 제외하되, 원본 데이터에서는 삭제하지 않습니다.
5. 상품 코드를 기준으로 "상품 마스터"에서 상품명, 상품군, 정상 가격을 가져옵니다.
6. 같은 상품 코드가 여러 개라면 판매 상태가 "판매 중"인 행을 우선 사용하고, 그래도 여러 개라면 최종 수정일이 가장 최근인 행을 사용합니다.
7. 상품 마스터에서 찾을 수 없는 상품 코드는 임의로 보완하지 말고 "확인 필요"로 표시합니다.
8. 수량 × 판매단가로 주문 금액을 계산합니다.
9. 정상 가격보다 판매단가가 30% 이상 낮은 주문은 "가격 확인 필요"로 표시합니다.
10. 상품군별 매출과 일자별 매출을 집계합니다.

결과는 다음 시트로 구성된 새 엑셀 파일로 만들어 주세요.

- 처리 요약
- 정리된 주문
- 확인 필요
- 상품군별 매출
- 일자별 매출

원본 CSV와 구글 드라이브의 상품 마스터는 수정하지 마세요.
```

## 예제 5.7 결과 파일을 구글 드라이브에 저장하기

```
앞에서 만든 `2027_06_주문내역_정리.xlsx` 파일을 내 구글 드라이브의 "월별 매출 정리/2027" 폴더에 저장해 주세요.

"2027" 폴더가 없다면 새로 만들어 주세요. 같은 이름의 파일이 이미 있다면 덮어쓰지 말고 파일 이름 뒤에 저장 날짜와 시간을 붙여 주세요. 저장이 끝나면 저장한 폴더와 파일 이름을 알려주세요.
```

## 예제 5.8 웹 검색으로 최신 시장 동향 파악

```
국내 프리랜서·1인 사업자 시장의 최신 동향을 조사해주세요. 특히 다음 내용을 포함해주세요.

- 시장 규모와 성장 현황 (최신 데이터)
- 주요 플랫폼과 커뮤니티의 최근 움직임
- 주목받는 신규 서비스나 트렌드
- 출처도 함께 알려주세요
```

## 예제 5.9 관심 주제의 최근 뉴스 정리

```
최근 3개월간 국내 전자책, 오디오북 시장 관련 뉴스를 검색해서 정리해주세요. 신규 서비스 출시, 이용자 동향, 주목받는 콘텐츠 트렌드를 중심으로 5~7개 항목으로 요약해주세요.
```
