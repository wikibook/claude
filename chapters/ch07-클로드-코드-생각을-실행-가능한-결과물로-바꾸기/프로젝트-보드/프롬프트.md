# 개인 프로젝트 추적 보드 — 사용한 프롬프트

『클로드 활용 입문서』 7.5.2절 예제 7.7의 [IN] 요청문과 7.5.3절의 보드 색상 후속 요청입니다.

## 1단계 — 보드 만들기 (예제 7.7)

```
개인 프로젝트 추적용 간단한 웹 보드를 만들어주세요. 할 일을 카드로 추가할 수 있고, 카드마다 제목, 마감일, 메모를 입력할 수 있으면 좋겠습니다. 카드를 "할 일", "진행 중", "완료" 세 열로 드래그해서 이동할 수 있으면 좋겠습니다. 내 컴퓨터에서 바로 쓸 수 있게 만들어주세요.
```

## 2단계 — 우선순위 색상 (7.5.3절 후속 요청)

```
방금 만든 프로젝트 보드에 카드 색상을 우선순위별로 다르게 적용해주세요.
```

> 이 후속 요청은 예제 번호가 붙어 있지 않은 본문 속 요청입니다(7.5.3절).
> 책에서는 긴급 레드·보통 그린·낮음 그레이 테두리로 결과가 나옵니다.

> 위 요청을 클로드 코드 세션에 붙여 넣으면 책과 같은 칸반 보드가 만들어집니다.
> 카드는 브라우저 로컬 저장소에 저장되도록 요청하면, 인터넷 연결 없이도 내 컴퓨터에서 바로 쓸 수 있습니다.
