# 이미지 파일 일괄 처리 — 사용한 프롬프트

『클로드 활용 입문서』 7.5.1절 예제 7.6의 [IN] 요청문입니다. 세 번의 요청으로
같은 작업을 한 번 처리하고, 스킬로 만들고, 이듬해에 다시 부르는 흐름입니다.
결과물은 변환된 이미지 파일이므로 저장소에는 프롬프트만 담았습니다.

## 1단계 — 이번 워크숍 사진 처리하기

```
photos 폴더에 팀 워크숍 사진이 47장 있습니다. 이 사진들을 모두 1200×800 크기로 맞추고, 파일 이름을 "2027_teamworkshop_001", "2027_teamworkshop_002" 형식으로 순서대로 바꿔주세요. 원본 파일은 photos_original 폴더에 따로 보관해주세요.
```

## 2단계 — 반복 작업을 스킬로 만들기

```
매년 워크숍마다 같은 작업을 반복합니다. 방금 한 작업을 스킬로 만들어주세요. 사진 크기와 이름 규칙, 원본 보관 방식은 그대로 쓰고, 연도와 행사 이름만 그때그때 바꿔서 쓸 수 있으면 좋겠습니다.
```

## 3단계 — 이듬해에 만든 스킬 부르기

```
/photo-organize 2028년 워크숍 사진입니다. photos 폴더에 넣어뒀습니다.
```

> 원본을 따로 보관하라는 요청처럼, "되돌릴 수 있는 안전장치"를 함께 부탁하면 안심하고 맡길 수 있습니다.
> 작업이 끝나면 변환된 이미지 몇 장을 열어 크기와 파일명이 의도대로인지 확인하세요.
