## 예제 2.1 모호한 프롬프트와 구체적인 프롬프트

### 요청 1

```

```

### 요청 2

```
저는 혼자 운영하는 온라인 쇼핑몰에서 20~30대 여성을 대상으로 친환경 화장품을 판매하고 있습니다. 월 마케팅 예산은 500만 원입니다. 최근 3개월간 신규 고객 유입이 20% 감소했습니다.

이 상황에서 신규 고객을 다시 늘리기 위한 마케팅 전략을 3가지 제안해 주세요. 각 전략마다 예상 비용, 기대 효과, 실행 기간을 포함해 주세요.
```

```
- 어조: 전문적이되 친근하게

- 제외: 경쟁사 언급, 과장된 효능 표현
```

```
고객 성공 사례를 아래 형식에 맞춰 작성해 주세요.

[형식 예시 1]
제목: "주문 처리 시간 60% 단축"
회사: 패스트푸드 체인 A사
문제: 매장별 재고 파악이 안 돼 본사 발주에 하루가 걸렸습니다.
해결: 실시간 재고 연동 시스템을 도입해 자동 발주 체계를 구축했습니다.

[형식 예시 2]
제목: "고객 문의 응답률 95% 달성"
회사: 온라인 쇼핑몰 B사

성과: 응답률 60% → 95%, 상담원 업무 부담 40% 감소
현장의 말: "단순 문의는 챗봇이, 복잡한 상담은 사람이."
출처: B사 CS팀장

---

이제 아래 정보를 위 형식에 맞춰 작성해 주세요.

회사: 중소 물류 업체 C사 (직원 45명)
상황: 배송 기사 15명의 경로를 수작업으로 배정하느라 매일 아침 2시간 소비
도입한 솔루션: AI 기반 배송 경로 최적화 시스템
결과: 경로 배정 시간 90% 감소, 연료비 25% 절감, 일일 배송 건수 20% 증가
```

## 예제 2.11 프로젝트 사용자 지정 지침 예시: 마케팅 콘텐츠 프로젝트

> 프로젝트 설정 화면의 **사용자 지정 지침**에 아래 내용을 붙여 넣으세요.

```
[프로젝트명]
2027 Q1 루나글로우 신제품 런칭 콘텐츠 제작

[역할]
비건 스킨케어 브랜드 '루나글로우'의 콘텐츠 담당자로서,
2027년 1분기 신제품 런칭에 맞춰 블로그·SNS·이메일 뉴스레터 콘텐츠를
일관된 톤으로 제작합니다.

[브랜드 정보]
- 주력 제품: 비건 스킨케어
- 타깃: 25~35세 여성
- 브랜드 분위기: 친근하고 감성적이되, 신뢰감을 잃지 않는 어조
- 글쓰기 원칙: 딱딱한 설명보다 공감을 우선하며, 전문 용어 남발 금지

[채널별 작성 규칙]

1. 블로그 포스트
   - SEO 키워드 반영
   - 감성적이지만 신뢰감 있는 톤 유지
   - "피부 트러블", "여드름" 등 부정적 단어 사용 금지 →
     "피부 컨디션", "맑고 편안한 피부" 등으로 순화

2. 인스타그램 / X 숏폼 카피
   - 200자 내외, 3~5개 버전 제안
   - 이모지는 게시물당 2~3개만 사용
   - 해시태그 5~8개 제안
   - 부정적 단어 사용 금지 (블로그와 동일)

3. 이메일 뉴스레터
   - 오픈율 개선을 목적으로 제목/본문 구성
   - 브랜드 톤앤매너 동일하게 적용

[공통 유의사항]
- 확인되지 않은 제품 스펙·출시일은 임의로 작성하지 않음
- 경쟁사(competitor) 언급 시 사실 기반으로만 서술
- 초안 작성 후 반드시 "검토 포인트"를 3줄 이내로 요약해서 함께 제시

[참고 자료]
- 루나글로우 브랜드 톤앤매너 가이드 (업로드 예정)
- 지난 분기 캠페인 성과 리포트 (업로드 예정)
```
