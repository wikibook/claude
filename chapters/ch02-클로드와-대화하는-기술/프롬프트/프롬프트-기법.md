# 프롬프트 기법 예제 — 구조화 · 단계별 검토 · Few-shot

『클로드 활용 입문서』 2.3절에서 다룬 세 가지 프롬프트 기법의 예제(2.8~2.10)를
그대로 복사해 쓸 수 있게 담았습니다. 대괄호 안 항목만 본인 상황으로 바꿔
클로드 대화창에 붙여 넣으면 됩니다. 각 예제 아래 접힌 부분을 펼치면
책에 실린 클로드의 응답 예시를 볼 수 있습니다.

---

## 1. 구조화된 프롬프트 (예제 2.8)

프롬프트가 길어지면 클로드가 지시를 놓치기도 합니다. 마크다운 제목(`#`, `##`)으로
'배경 정보 / 작성 조건 / 참고 톤'을 나눠 두면 클로드가 모든 조건을 빠짐없이 반영합니다.

```
# 작업 요청: 제품 출시 보도자료 작성

## 배경 정보
- 회사명: [회사 이름]
- 제품명: [제품 이름]
- 출시일: [출시 날짜]
- 특징: [핵심 특징 3가지]

## 작성 조건
- 분량: [글자 수]
- 어조: [예: 전문적이되 친근하게]
- 필수 포함: 제품 특징 3가지, 대표 인용문, 구매 정보
- 제외: 경쟁사 언급, 과장된 효능 표현

## 참고할 톤 예시
"[원하는 톤을 보여주는 한 문장]" > 이런 톤으로 써주세요.
```

> **💡 팁:** 프롬프트 안에서 입력 데이터와 지시를 구분선(`---`)으로 나누거나,
> `<자료>...</자료>`처럼 꺾쇠 태그로 감싸면 클로드가 각 영역의 역할을 더 정확히 구분합니다.
> 꺾쇠 태그 활용법은 [XML 태그 공식 문서](https://platform.claude.com/docs/ko/build-with-claude/prompt-engineering/use-xml-tags)에서 확인하세요.

<details>
<summary>클로드의 응답 예시 보기 (에코클린 올인원 세제 사례)</summary>

```
**그린라이프, 하나로 끝내는 친환경 세제 '에코클린 올인원' 출시**

친환경 생활용품 기업 그린라이프가 7월 1일 식물성 올인원 세제 '에코클린 올인원'을 출시합니다.

에코클린 올인원은 세탁, 주방, 욕실까지 한 병으로 해결하는 다목적 세제입니다. 100% 식물성
원료만을 사용해 피부가 민감한 분도 안심하고 쓸 수 있으며, 생분해도가 높아 수질 오염 걱정을 줄였습니다.

이 제품의 가장 큰 특징은 리필 시스템입니다. 처음 한 번만 본품 용기를 구매하면 이후에는
리필 파우치로 교체할 수 있어, 기존 대비 플라스틱 사용량을 80% 줄일 수 있습니다.

그린라이프 김지현 대표는 "매일 쓰는 세제 하나를 바꾸는 것만으로도 1년에 플라스틱 용기 12개를
줄일 수 있습니다"라고 밝혔습니다.

문의: 그린라이프 고객센터 1588-0000
```
</details>

## 2. 단계별 검토 (예제 2.9)

복잡한 판단·계산에서 "바로 답만 주세요"라고 하면 클로드가 성급한 결론을 내리기 쉽습니다.
**"단계별로 판단해 주세요"** 한 마디를 더하면 필요한 항목을 순서대로 검토해 정확도가 올라갑니다.
숫자 비교, 여러 선택지 저울질, 원인·결과 추적처럼 중간 과정이 중요한 문제에 특히 잘 맞습니다.

```
[비교할 대상]을 두고 [판단 기준]으로 어느 쪽이 가장 유리한지 단계별로 판단해 주세요.

[현황]
- [조건 1]
- [조건 2 — 시간에 따라 변하는 값이 있다면 함께]

[선택지 정보]
- 선택지 A: [비용/조건 구조]
- 선택지 B: [비용/조건 구조]
- 선택지 C: [비용/조건 구조]
```

<details>
<summary>클로드의 응답 예시 보기 (협업 도구 3년 총비용 비교)</summary>

```
단계별로 계산해 보겠습니다. 모두 연 결제 기준으로 비교하겠습니다.

**1단계: 1년 차(8명) 비용 계산**
- 스타터: 8명 × 9,000원 × 12개월 × 0.80 = 691,200원
- 팀: 8명 × 15,000원 × 12개월 × 0.75 = 1,080,000원
- 비즈니스: 200,000원 × 12개월 = 2,400,000원

**2단계: 2년 차(12명) 비용 계산**
- 스타터: 12명 × 9,000원 × 12개월 × 0.80 = 1,036,800원
- 팀: 12명 × 15,000원 × 12개월 × 0.75 × 0.90 = 1,458,000원 (11명 이상 추가 할인)
- 비즈니스: 2,400,000원

**3단계: 3년 합산**
| 플랜 | 3년 합산 |
|------|---------|
| 스타터 | 3,024,000 |
| 팀 | 4,360,500 |
| 비즈니스 | 7,200,000 |

**4단계: 종합 판단**
3년 합산 기준으로 스타터 플랜이 약 302만 원으로 가장 저렴합니다. 다만 스타터 플랜에
필요한 기능이 모두 포함되어 있는지 별도로 확인하시기 바랍니다.
```
</details>

## 3. Few-shot 프롬프팅 (예제 2.10)

말로 설명하기 어려운 형식·톤·스타일은 **예시를 1~3개 보여주는** 편이 정확합니다.
클로드가 예시에서 제목 패턴, 항목 길이, 인용문 느낌까지 파악해 그대로 따라 씁니다.

```
[결과물]을 아래 형식에 맞춰 작성해 주세요.

[형식 예시 1]
[원하는 형식의 완성 예시를 하나 그대로 붙여넣기]

[형식 예시 2]
[가능하면 예시 하나 더 — 1~3개가 적당]

---

이제 아래 정보를 위 형식에 맞춰 작성해 주세요.

[실제로 작성할 내용의 재료]
```

> **💡 팁:** 예시는 1~3개면 충분합니다(많으면 오히려 혼란). 예시의 품질이 결과 품질을 좌우하며,
> 예시와 실제 요청을 구분선(`---`)으로 나누면 "여기까지 예시, 여기부터 실제 작업"임을 정확히 인식합니다.

<details>
<summary>클로드의 응답 예시 보기 (물류 업체 고객 성공 사례)</summary>

```
제목: "아침 2시간의 경로 배정, 10분으로 줄이다"
회사: 물류 업체 C사
문제: 배송 기사 15명의 경로를 매일 아침 담당자가 수작업으로 배정했습니다. 2시간이 걸리는 데다,
경험에 의존한 경로 배정은 불필요한 우회를 만들어 연료비가 계속 늘었습니다.
해결: AI 기반 배송 경로 최적화 시스템을 도입해 교통 상황, 배송지 밀집도, 기사별 담당 구역을
종합 분석한 최적 경로를 자동 생성했습니다.
성과: 경로 배정 시간 2시간 → 10분(90% 감소), 월 연료비 25% 절감, 일일 배송 건수 20% 증가
현장의 말: "지도 펼쳐놓고 머리 싸매던 아침이 사라졌습니다."
출처: C사 물류팀장
```
</details>

> **함께 쓰면 강해집니다.** 역할 부여(2.2절) + 구조화된 프롬프트(2.3.2) + Few-shot(2.3.4)을
> 한 프롬프트에 같이 넣어 보세요. "당신은 테크 블로그 에디터입니다"로 역할을 정하고,
> 마크다운 구조로 조건을 정리하고, 원하는 글의 예시를 하나 붙이는 식입니다.
