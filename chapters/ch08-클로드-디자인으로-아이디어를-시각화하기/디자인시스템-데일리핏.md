# 디자인 시스템 — 데일리핏 (예시)

『클로드 활용 입문서』 8.3.3절(예제 8.4)에서 만든 브랜드 디자인 시스템 설정입니다.
클로드 디자인 사이드바의 **Design Systems → Create New**에서 아래 값을 입력하면,
이후 새 슬라이드·목업을 만들 때 이 브랜드 색상과 폰트가 자동으로 적용됩니다.

## 설정 값

| 항목 | 값 |
| --- | --- |
| 이름 | 데일리핏 |
| 주 색상 | `#16A34A` (그린), `#84CC16` (라임) |
| 보조 색상 | 흰색 배경, `#202124` 텍스트 |
| 폰트 방향 | 제목 Bold, 본문 16px 이상 (가독성 우선) |

## 클로드 디자인에 넣을 설명문

```
우리 브랜드 디자인 시스템을 새로 만들어주세요.

이름: 데일리핏
주 색상: #16A34A (그린), #84CC16 (라임)
보조 색상: 흰색 배경, #202124 텍스트
폰트: 제목은 굵게, 본문은 16px 이상 가독성 우선
```

> **💡 팁 — 작업 규칙도 함께(책 8.3.3절)**
> "항상 3열 그리드 레이아웃 사용", "텍스트는 왼쪽 정렬" 같은 규칙을 디자인 시스템 메모에 적어두면
> 프로젝트마다 따로 설명하지 않아도 됩니다.

> **코드로 이어갈 때** — 클로드 디자인 시안을 HTML·프론트엔드로 옮긴 뒤 [Impeccable](https://impeccable.style/)의 `/impeccable document`로 위 색상·폰트 규칙을 `DESIGN.md`에 정리해 두면, 이후 `/polish`·`/colorize` 명령이 같은 브랜드를 유지합니다.
