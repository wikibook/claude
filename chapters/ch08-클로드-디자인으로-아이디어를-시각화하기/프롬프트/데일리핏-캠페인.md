# 데일리핏 캠페인 — 하나의 브랜드로 다섯 가지 결과물 만들기

『클로드 활용 입문서』 8.3절의 예제(8.1~8.6)입니다. 가상 브랜드 **'데일리핏 100일 루틴'** 하나로
목업·슬라이드·Q&A·인포그래픽·운영 문서·애니메이션 랜딩까지 이어서 만들어 봅니다. 클로드 디자인의
결과물은 캔버스에서 생성되어 코드로 내려받는 형태가 아니므로, 여기에는 **그대로 따라 할 수 있는
요청(프롬프트)**을 담았습니다. 각 요청의 대괄호만 본인 상황으로 바꿔 쓰세요.

> **더 좋은 초안을 얻는 요청 구조:** 목적(무엇을·왜) · 레이아웃(섹션 구성) · 내용(들어갈 텍스트·데이터) ·
> 대상(볼 사람) 네 가지를 함께 넣으면 완성도가 크게 올라갑니다. 빠뜨린 정보는 클로드가 되물어 보완합니다.

---

## 1. 웹/앱 목업 — 프로토타입 (예제 8.1)

첫 화면에서 **프로토타입**을 선택하고 시작합니다. 화면 중심 기획(홈페이지·앱·대시보드)에 적합합니다.

```
[대상]의 [무엇] 초안을 만들어주세요.

구성:
- 히어로 섹션: [핵심 요소]
- [주요 섹션]: [내용]
- 연락처/CTA: [내용]

톤은 [분위기]으로 해주세요. 배경은 [색 계열]로 부탁합니다.
```
> 특정 요소를 클릭해 **인라인 댓글(Mark up)**로 "여기에 다크/라이트 모드 버튼 추가"처럼 부분 수정을 요청할 수 있습니다.

## 2. 프레젠테이션 슬라이드 (예제 8.2)

**슬라이드 덱** 유형을 선택합니다. "슬라이드 만들어줘"가 아니라 **누구에게 무엇을 전달하는 자료인지** 먼저 설명하는 것이 핵심입니다.

```
[캠페인/주제]을 [대상]에게 [시간] 발표해야 합니다. 슬라이드 [매수] 이내로 구성해주세요.

각 슬라이드에는:
- 제목과 핵심 메시지
- 발표 스크립트 한두 줄

[핵심 내용]:
- 이름 / 목표 / 예산 / 핵심 차별점 …
```

## 3. 예상 Q&A 슬라이드 (예제 8.3)

만든 슬라이드에 이어, 날카로운 질문 대비 슬라이드를 덧붙입니다. **누구의 입장**으로 질문을 뽑을지 지정하면 예리해집니다.

```
위 발표 자료를 바탕으로 마지막 슬라이드 뒤에 이어질 Q&A 대응 슬라이드를 만들어주세요.
청중이 날카롭게 물어볼 법한 질문 [개수]가지와 답변이 포함되면 됩니다.
[가장 엄격한 입장 — 예: 예산과 ROI에 엄격한 투자자] 입장으로 질문을 뽑아주세요.
```

## 4. 한 장 인포그래픽 (예제 8.4)

**데이터 + 강조할 메시지**를 함께 주면, 숫자 나열이 아니라 핵심이 드러나는 시각 자료가 나옵니다.

```
아래 데이터를 한 장짜리 인포그래픽 대시보드로 만들어주세요.
발표 슬라이드에 바로 삽입할 예정이니 핵심 지표가 한눈에 파악되도록 시각화해주세요.

- 성과 데이터: [지표들 — 예: 참여자 512명(목표 500 달성), SNS 노출 61만, 전환 198건 …]
- 주요 메시지: [강조할 3가지]
```

## 5. 운영 문서 — 혼자 읽히는 자료 (예제 8.5)

**문서 템플릿**을 선택합니다. 슬라이드와 달리 문서는 옆에서 설명할 발표자가 없으므로, 맥락과 흐름이 글 안에서 이어져야 합니다.

```
[캠페인/주제]을 실무팀이 보고 바로 실행할 수 있는 한 장짜리 운영 문서로 만들어주세요.

다음 내용을 담아주세요.
- 한 줄 요약과 목표
- 예산 배분 / 운영 일정 / 역할 분담
- 주차별 점검 항목

읽고 바로 실행할 수 있게, 표와 체크리스트를 섞어 깔끔하게 정리해주세요.
```
> 이어서 "리스크 대응 항목을 표로 추가해 주세요", "사내 공유용이니 톤을 차분하게 바꿔 주세요"처럼
> 페이지·톤을 덧붙여 다듬을 수 있습니다. **긴 문서는 "먼저 목차만 제안해 주세요"로 구조부터 잡으세요.**

## 6. 스크롤 애니메이션 랜딩 (예제 8.6)

**애니메이션 템플릿**을 선택합니다. 움직임이 결과물의 중심입니다. 웹 화면 안에서 동작하며, 영상 파일 제작과는 다릅니다.

```
[캠페인] 출시를 알리는 한 페이지 랜딩을 만들고, 화면을 내릴 때 자연스럽게 움직이도록 해주세요.

- 첫 화면: [메시지가 부드럽게 떠오르기]
- 다음 구간: [숫자 카운트 등 효과]
- 아래로 내리면: [단계별로 차례차례 나타나기]
- 마지막: [CTA 버튼 강조]

전체 톤은 [분위기]으로 부탁합니다.
```
> **움직임은 절제할수록 좋습니다.** 모든 요소가 움직이면 메시지가 묻힙니다. "핵심 메시지와 신청 버튼에만
> 움직임을 넣어 주세요"처럼 범위를 좁히세요.
