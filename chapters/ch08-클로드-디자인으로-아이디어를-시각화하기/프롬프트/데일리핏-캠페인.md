# 데일리핏 캠페인 — 책 예제 완전문

> 책 8.3절 예제 8.1~8.6의 [IN] 요청문입니다.

## 예제 8.1 프리랜서 포트폴리오 홈페이지 초안 요청

### 요청 1

```
프리랜서 UX 디자이너의 포트폴리오 홈페이지 초안을 만들어주세요.

구성:
- 히어로 섹션: 이름, 한 줄 소개, '프로젝트 보기' 버튼
- 최근 프로젝트 3개: 이미지 썸네일, 제목, 짧은 설명
- 연락처: 이메일 링크, 링크드인 아이콘

톤은 깔끔하고 모던하게 해주세요. 배경은 흰색 계열로 부탁합니다.
```

### 요청 2

```
CONTACT 버튼 오른쪽에 다국어 버튼과 다크/라이트 모드 버튼을 추가해주세요.
```

## 예제 8.2 캠페인 발표용 슬라이드 구성 요청

```
신제품 '데일리핏' 마케팅 캠페인을 팀에 15분 발표해야 합니다.
슬라이드 10장 이내로 구성해주세요.

각 슬라이드에는:
- 제목과 핵심 메시지
- 발표 스크립트 한두 줄

캠페인 내용:
- 이름: 100일 루틴
- 목표: 참여자 500명, 신규 전환 200건, 완주율 30%
- 예산: 500만 원 (광고 200만, 인플루언서 100만, 제품 100만, 환불 충당금 75만, 제작 25만)
- 핵심 차별점: 100일 완주 시 챌린지 참가비 5,000원 전액 환불
```

> **HTML로 배포할 때** — 캔버스 슬라이드 대신 브라우저에서 바로 열 수 있는 덱이 필요하면 [Frontend Slides](https://github.com/zarazhangrui/frontend-slides) 스킬에 위 요청문을 넘기세요. 스타일 미리보기 3종 중 하나를 고른 뒤 단일 HTML 파일로 생성됩니다. 설치·명령은 [8장 README](../README.md#frontend-slides--html-발표-자료-만들기)를 참고하세요.

## 예제 8.3 날카로운 예상 질문 대비 요청

```
위 발표 자료를 바탕으로 마지막 슬라이드 뒤에 이어질 Q&A 대응 슬라이드를 만들어주세요. 청중이 날카롭게 물어볼 법한 질문 5가지와 그에 대한 답변이 포함되면 됩니다. 예산과 ROI에 가장 엄격한 투자자 입장으로 질문을 뽑아주세요.
```

## 예제 8.4 캠페인 성과를 한 장 마케팅 비주얼로 만들기

```
아래 데이터를 한 장짜리 인포그래픽 대시보드로 만들어주세요. 발표 슬라이드에 바로 삽입할 예정이니 핵심 지표가 한눈에 파악되도록 시각화해주세요.

- 캠페인 성과 데이터: 참여자 512명(목표 500명 달성), SNS 노출 61만 회, 신규 구매 전환 198건(목표 200건 근접), 30일 지속률 74%, 평균 제품 평점 4.3/5.0
- 주요 메시지: 참여 목표 달성, 전환 목표 근접, 30일 지속률 양호
```

## 예제 8.5 캠페인 운영 문서 한 장으로 정리하기

### 요청 1

```
'데일리핏 100일 루틴' 캠페인을 실무팀이 보고 바로 실행할 수 있는 한 장짜리 운영 문서로 만들어주세요.

다음 내용을 담아주세요.
- 캠페인 한 줄 요약과 목표(참여자 500명, 신규 전환 200건, 완주율 30%)
- 예산 배분(광고 200만, 인플루언서 100만, 제품 100만, 환불 충당금 75만, 제작 25만)
- 운영 일정: 사전 준비 → 모집 → 100일 진행 → 정산
- 역할 분담: 마케팅, 콘텐츠, CS
- 주차별 점검 항목

읽고 바로 실행할 수 있게, 표와 체크리스트를 섞어 깔끔하게 정리해주세요.
```

### 요청 2

```
좋습니다. 이 문서에 두 번째 페이지를 더 붙여주세요.

캠페인을 진행하다 막힐 수 있는 리스크와 대응 방안을 정리하는 페이지입니다.
- 예상 리스크 4~5가지(모집 부진, 중도 이탈, 환불 폭증, 콘텐츠 일정 지연 등)
- 각 리스크의 경고 신호, 대응 방법, 담당
- 표로 한눈에 보이게 정리

첫 페이지 운영 문서와 같은 서식과 톤을 유지해주세요.
```

## 예제 8.6 캠페인 랜딩에 스크롤 애니메이션 더하기

```
'데일리핏 100일 루틴' 캠페인 출시를 알리는 한 페이지 랜딩을 만들고, 화면을 내릴 때 자연스럽게 움직이도록 해주세요.

- 첫 화면: 캠페인 이름과 한 줄 메시지가 부드럽게 떠오르기
- 다음 구간: 지금까지 사전 신청한 인원이 0부터 올라가는 숫자 효과
- 아래로 내리면: '신청 → 100일 루틴 → 전액 환불' 세 단계가 차례로 나타나기
- 마지막: 신청 버튼이 시선을 끌도록 강조

전체 톤은 활기차고 산뜻하게 부탁합니다.
```
