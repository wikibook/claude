# 디자인 시스템 — 데일리핏 (예시)

『클로드 활용 입문서』 8.4.3절 예제 8.7에서 만든 브랜드 디자인 시스템 설정입니다.
클로드 디자인 사이드바의 **Design Systems → Create New**에서 아래 값을 입력하면,
이후 새 슬라이드·목업을 만들 때 이 브랜드 색상과 폰트가 자동으로 적용됩니다.

## 설정 값

| 항목 | 값 |
| --- | --- |
| 이름 | 데일리핏 |
| 성격 | 건강 습관을 가볍게 돕는 모바일 앱. 활기차고 깔끔한 느낌 |
| 강조 색상 | `#22C55E` (민트그린) |
| 본문 글자 | `#0F172A` (진한 네이비) |
| 배경 | `#F8FAFC` (연한 회색), 여백은 넉넉하게 |
| 글꼴 | 제목은 두껍고 둥근 산세리프, 본문은 읽기 편한 고딕체 |
| 버튼 | 모서리를 둥글게, 초록색으로 채운 버튼이 기본 |
| 사진 | 밝은 자연광 아래 운동·식사 장면. 어둡거나 과보정한 사진은 제외 |
| 말투 | 강요하지 않고 응원하는 어조 ("오늘도 한 걸음!") |

## 클로드 디자인에 넣을 설명문

책 예제 8.7의 [IN] 요청문 그대로입니다.

```
데일리핏 브랜드 규칙

- 성격: 건강 습관을 가볍게 돕는 모바일 앱. 활기차고 깔끔한 느낌.
- 핵심 색상: 강조 색상은 민트그린(#22C55E), 본문 글자는 진한 네이비(#0F172A)
- 보조 색상: 연한 회색(#F8FAFC)을 배경으로 사용하고 여백은 넉넉하게 구성
- 글꼴: 제목은 두껍고 둥근 산세리프, 본문은 읽기 편한 고딕체
- 버튼: 모서리를 둥글게 처리하고 초록색으로 채운 버튼을 기본으로 사용
- 사진: 밝은 자연광 아래에서 촬영한 운동·식사 장면. 어둡거나 지나치게 보정한 사진은 사용하지 않음
- 말투: 강요하지 않고 응원하는 어조. "오늘도 한 걸음!"과 같은 문장 사용
```

> **💡 팁 — 작업 규칙도 함께(책 8.4.3절)**
> "항상 3열 그리드 레이아웃 사용", "텍스트는 왼쪽 정렬" 같은 규칙을 디자인 시스템 메모에 적어두면
> 프로젝트마다 따로 설명하지 않아도 됩니다.

> **디자인 시스템을 만들기 전 — 업종별 제안 받기** — 헬스·라이프스타일 앱 맥락에서 팔레트·타이포 후보를 빠르게 비교하려면 [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)를 써 보세요. `uipro init --ai claude` 설치 후 "데일리핏 브랜드에 맞는 디자인 시스템 제안해줘"처럼 요청하거나, CLI로 `python3 .claude/skills/ui-ux-pro-max/scripts/search.py "habit tracker wellness" --design-system -p "데일리핏" -f markdown`을 실행하면 Primary·Secondary 색과 폰트 조합이 나옵니다. 결과를 클로드 디자인 Design Systems 설정값으로 옮기면 됩니다.

> **코드로 이어갈 때** — 클로드 디자인 시안을 HTML·프론트엔드로 옮긴 뒤 [Impeccable](https://impeccable.style/)의 `/impeccable document`로 위 색상·폰트 규칙을 `DESIGN.md`에 정리해 두면, 이후 `/polish`·`/colorize` 명령이 같은 브랜드를 유지합니다.
