# 1장 클로드와 일하는 시대

> **책 1장** 독자를 위한 보충 자료입니다.
> 클로드 기능 변화에 맞춰 지속적으로 업데이트합니다.

1장은 클로드를 처음 쓰기 위한 개념과 준비를 다룹니다. 별도 실습 파일보다는, 가입·앱 설치·모델
이해에 필요한 링크와 개념을 정리했습니다. 처음 시작한다면 아래 세 곳부터 확인하세요.

- **[시작하기 — 가입·설치·요금제 링크 모음](../../resources/시작하기.md)** — 클로드 웹, 앱 다운로드, 요금제, 도움말을 한곳에(책 1.2절).
- **[용어집](../../resources/용어집.md)** — 클로드·모델·프로젝트 등 책 전반에 반복되는 용어 정리(1장 전체).
- **[공식 문서 링크](../../resources/공식문서-링크.md)** — 책 전반에서 참조하는 공식 문서 모음(1장 이후).

## 시작 강의 — 클로드 처음 익히기

#### 클로드 101 (공식 입문 강의)
클로드가 처음이라면 여기서 시작하세요. 앤트로픽이 만든 공식 입문 강의로, 1장의 개념을 실제 화면과
함께 따라가며 익힐 수 있습니다.
→ [Claude 101 (Anthropic 공식 강의)](https://anthropic.skilljar.com/claude-101)

## 공식 문서

상황에 맞게 고르는 기준을 잡을 수 있습니다.
→ [클로드 모델 개요](https://docs.anthropic.com/en/docs/about-claude/models/overview)
