# 4장 예제 프롬프트

> 책 4장 예제 4.1~4.9의 [IN] 요청문입니다. 그대로 복사해 사용하세요.
> 예제 4.2~4.5는 `메모-할일-정리` 스킬을, 예제 4.6~4.9는 `학습-보조` 스킬을 만들고 쓰는 흐름입니다.
> 이 요청으로 만들어지는 결과물은 같은 폴더의 [`메모-할일-정리/SKILL.md`](../메모-할일-정리/SKILL.md)와 [`학습-보조/SKILL.md`](../학습-보조/SKILL.md)에서 확인할 수 있습니다.

## 예제 4.1 공식 스킬로 회의 내용 엑셀 파일 만들기

```
아래 내용으로 엑셀 파일을 만들어 주세요. 시트 이름은 "8월 업무", 항목 / 담당자 / 마감일 / 완료 여부 열로 구성해 주세요.

- 마케팅 보고서 초안: 이수진, 8/9
- SNS 콘텐츠 캘린더: 박민준, 8/12
- 거래처 미팅 자료: 김하은, 8/14
- 분기 예산 정리: 최준혁, 8/20
```

## 예제 4.2 메모 정리 스킬 만들기: 목표 전달

```
/skill-creator 스킬을 만들고 싶습니다. 슬랙 메시지, 회의 메모, 이메일 조각 같은 걸 붙여넣으면 마크다운 체크리스트로 정리해 주는 스킬입니다. 담당자와 마감이 있는 일은 따로 묶어주면 좋겠습니다.
```

## 예제 4.3 메모 정리 스킬: 샘플 데이터 전달

```
분류는 마감 긴급도와 업무/개인 두 축으로 나눠주세요. 담당자/마감이 없는 건 "확인 필요"로 모아주세요. 이모지는 섹션 제목에만 가볍게 써주세요. 아래가 제가 실제로 자주 만드는 메모 뭉치입니다.

- 담당자에게 내일까지 보고서 리뷰 요청
- 영업팀 담당자에게 견적 자료 보내기 (이번주 안에)
- 사무실 커피 다 떨어짐
- 월요일 회의 때 Q2 실적 발표 준비 필요
- 인사팀에서 연말정산 서류 언제까지였지 확인
- 주말에 강아지 병원 예약
```

## 예제 4.4 완성된 스킬을 실전에서 호출하기

```
/memo-organizer

오늘 정신없이 메모한 것들입니다. 정리해주세요.

오전에 회의 진행자가 내일 회의 자료에 경쟁사 가격 비교 추가 요청. 점심에 디자이너 수민 님에게 배너 시안 피드백 이번주까지 줘야 함. 아 그리고 프린터 토너 주문 넣기. 다음 달 워크숍 장소 후보지 3군데 정해서 공유하기. 건강검진 12월 중이었던 거 같은데 예약 확인. 아이 학원 상담 다음주 화요일 오후 3시.
```

## 예제 4.5 스킬 개선 요청

```
/skill-creator '메모-할일-정리' 스킬을 조금 고쳐주세요. 개인 섹션이 맨 아래에 있는데 맨 위로 올려주면 좋겠습니다. 그리고 마감이 "오늘"인 항목은 🚨 이모지로 눈에 띄게 해주세요.
```

## 예제 4.6 새 분야 개념 이해: 눈높이 설명 요청

```
저는 마케터입니다. 이번에 중요한 클라이언트 미팅을 앞두고 있는데 재무제표를 읽어야 할 것 같습니다. 재무제표가 무엇인지, 그리고 손익계산서·재무상태표·현금흐름표가 각각 무엇을 보여주는지 마케터 눈높이에서 쉽게 설명해주세요. 비유를 써서 설명해주세요.
```

## 예제 4.7 4주 학습 계획 세우기

```
저는 마케터입니다. GA4와 기본적인 데이터 해석 능력을 4주 안에 실무 수준으로 익히고 싶습니다. 지금은 GA4를 열어서 어떤 숫자를 봐야 하는지조차 잘 모르는 수준입니다. 하루 30분~1시간 정도 투자할 여유가 있습니다. 4주 학습 계획을 만들어주세요.
```

## 예제 4.8 퀴즈 생성 및 오답 해설 요청

```
방금 재무제표를 배웠습니다. 제가 얼마나 이해했는지 확인할 수 있게 퀴즈 5문제를 내주세요. 마케터 실무 맥락에서 적용할 수 있는 문제로 구성해주세요. 정답은 제가 먼저 맞혀볼 수 있게 문제만 먼저 보여주세요.
```

## 예제 4.9 학습 보조 스킬 만들기

```
/skill-creator 학습 보조 스킬을 만들고 싶습니다.
- 새 개념을 설명할 때는 항상 비유를 먼저 써주세요
- 설명 후에는 제 배경에 맞는 퀴즈 3개를 자동으로 내주세요
- 틀린 문제는 다른 방식으로 다시 설명해주세요
```
