# 메모-할일-정리

여기저기 흩어진 업무 메모를 할 일 목록으로 정리하는 스킬입니다.
책 『클로드 활용 입문서』 4.3절(예제 4.2~4.5)에서 skill-creator로 만든 스킬을 같은 동작으로 재현했습니다.

## 무엇을 하는 스킬인가

슬랙 메시지, 회의 메모, 이메일 끝에 슬쩍 들어온 요청, 퇴근길에 떠오른 생각처럼 출처도 형식도 제각각인 텍스트를 받아, 할 일만 골라 깔끔한 마크다운 체크리스트로 돌려줍니다.

## 정리 규칙

1. 입력에서 **실제 행동이 필요한 항목(할 일)만** 추립니다. 단순 정보나 잡담은 제외합니다.
2. 분류는 **마감 긴급도**와 **업무/개인** 두 축으로 나눕니다.
3. **담당자나 마감이 없어 분류가 애매한 항목**은 `❓ 확인 필요` 섹션에 모읍니다.
4. 각 항목은 체크박스(`- [ ]`)로 적고, 괄호 안에 담당자·마감 같은 맥락을 짧게 덧붙입니다.
5. **이모지는 섹션 제목에만** 가볍게 씁니다. 항목 본문에는 넣지 않습니다.

## 출력 형식

아래 섹션 순서를 따릅니다. 해당하는 항목이 없는 섹션은 생략합니다.

```markdown
## 🏠 개인

- [ ] (개인 할 일) (맥락)

## 🚨 오늘 마감

- [ ] (오늘까지 끝내야 하는 일) (맥락)

## 🔥 이번 주 마감

- [ ] (이번 주 안에 끝낼 일) (맥락)

## 📅 다음 주 이후

- [ ] (다음 주 이후 일정) (맥락)

## ❓ 확인 필요

- [ ] (담당자·마감이 불확실해 확인이 필요한 일)
```

> 섹션 순서는 책 4.3절 마지막 단계(예제 4.5)에서 다듬은 형태를 따릅니다.
> `🏠 개인`을 맨 위로, 마감이 오늘인 항목은 `🚨 오늘 마감`으로 분리했습니다.
> 순서나 섹션 이름은 본인 업무 흐름에 맞게 바꿔도 됩니다.

## 사용 예

입력:

```
오전에 회의 진행자가 내일 회의 자료에 경쟁사 가격 비교 추가 요청. 점심에 디자이너 최 선생에게
배너 시안 피드백 이번주까지 줘야 함. 아 그리고 프린터 토너 주문 넣기. 다음 달 워크숍 장소
후보지 3군데 정해서 공유하기. 건강검진 12월 중이었던 거 같은데 예약 확인.
```

출력:

```markdown
## 🏠 개인
- [ ] 프린터 토너 주문

## 🔥 이번 주 마감
- [ ] 내일 회의 자료에 경쟁사 가격 비교 추가 (회의 진행자 요청)
- [ ] 배너 시안 피드백 전달 (디자이너 최 선생, 이번 주)

## 📅 다음 주 이후
- [ ] 다음 달 워크숍 장소 후보 3곳 선정 후 공유

## ❓ 확인 필요
- [ ] 건강검진 예약: 12월 예정 여부 재확인
```

> (이 입력에는 "오늘 마감" 항목이 없어 `🚨 오늘 마감` 섹션은 나타나지 않습니다.)
