# 클로드 태그 도입 체크리스트

책 10.3절을 읽고 팀에 클로드 태그를 들일지 검토할 때 사용할 점검표입니다.
세부 화면과 조건은 바뀔 수 있으므로, 실제 설정 전에는 관리 콘솔과 공식 안내를 다시 확인하세요.

## 1. 사용 조건

- [ ] 조직이 Team 또는 Enterprise 요금제를 사용한다.
- [ ] 설정을 진행할 Primary Owner 또는 Owner가 정해져 있다.
- [ ] 테스트할 슬랙 워크스페이스와 파일럿 채널이 정해져 있다.

## 2. 채널 범위

- [ ] 처음에는 한 팀의 한 채널에서 시작한다.
- [ ] 공개 채널과 비공개 채널의 정보 경계를 구분한다.
- [ ] 민감한 고객 정보, 인사 정보, 계약 정보가 오가는 채널은 제외하거나 별도 검토한다.

## 3. 연결할 도구

- [ ] 처음 연결할 도구를 최소화한다.
- [ ] 코드 저장소, 티켓 관리, 데이터 저장소별 접근 권한을 따로 확인한다.
- [ ] 클로드가 쓰는 신원을 사람 계정과 구분해 기록에 남길 수 있는지 확인한다.

## 4. 비용과 알림

- [ ] 조직 전체 사용량 한도를 정한다.
- [ ] 파일럿 채널 사용량 한도를 정한다.
- [ ] 사용량 알림을 받을 사람을 정한다.
- [ ] 채널 작업과 개인 다이렉트 메시지 작업의 청구 기준을 팀에 안내한다.

## 5. 운영 규칙

- [ ] 채널에서 클로드에게 맡겨도 되는 일과 안 되는 일을 문장으로 정리한다.
- [ ] 장애, 배포, 고객 대응처럼 중요한 결과는 사람이 최종 확인한다는 원칙을 둔다.
- [ ] 루틴을 만들 때 시간대와 중지 방법을 함께 기록한다.
- [ ] 파일럿이 끝난 뒤 효과, 비용, 보안 이슈를 회고하고 확장 여부를 결정한다.
