# 10장 클로드 태그, 팀 채팅 속의 클로드

> **책 10장** 독자를 위한 보충 자료입니다.
> 클로드 태그는 팀·조직 단위 기능이므로, 실제 도입 전에는 관리 콘솔과 공식 안내에서 최신 조건을 확인하세요.

## 이 장의 보충 자료

책 10장은 개인 실습보다 팀 채팅 안에서 클로드를 어떻게 부르고 관리할지 이해하는 데 초점을 둡니다.
이 폴더에는 책의 대표 장면을 다시 써 볼 수 있는 프롬프트와 도입 전 점검표를 정리했습니다.

#### 💬 예시 프롬프트
배포 오류 조사, 지표 집계, 가격 정책 결정 기록, 루틴 요청 등 슬랙에서 `@Claude`를 부르는 대표
장면을 담았습니다(10.2절 예제 10.1~10.3).
→ [`예시-프롬프트.md`](예시-프롬프트.md)

#### ✅ 도입 체크리스트
요금제, 권한, 채널 범위, 비용, 보안까지 팀에 클로드 태그를 들이기 전에 확인할 항목입니다(10.3절).
→ [`도입-체크리스트.md`](도입-체크리스트.md)

## 활용 방법

1. 팀 채널에 클로드 태그가 연결되어 있는지 확인합니다.
2. 처음 쓰는 채널에서는 `@Claude 이 채널에서 무엇에 접근할 수 있나요?`라고 먼저 물어봅니다.
3. [`예시-프롬프트.md`](예시-프롬프트.md)의 요청문을 팀 상황에 맞게 바꿔 씁니다.
4. 도입을 검토하는 관리자라면 [`도입-체크리스트.md`](도입-체크리스트.md)로 최소 권한, 예산, 기록 범위를 확인합니다.

> 클로드 태그의 결과는 채널 구성원에게 공개됩니다.
> 고객 정보, 내부 수치, 장애 원인처럼 민감한 내용을 다룰 때는 팀의 보안 정책과 접근 권한을 먼저 확인하세요.
