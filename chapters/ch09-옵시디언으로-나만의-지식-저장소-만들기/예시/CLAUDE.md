# 이 볼트의 규칙

이 볼트는 개인 지식 저장소입니다. 클로드는 원본 자료를 보존하면서 위키 페이지를 정리하고, 작업 결과를 사람이 검토할 수 있게 남깁니다.

## 폴더 구조

- `sources/`: 원본 자료. 읽기 전용으로 다루고 직접 수정하지 않습니다.
- `wiki/`: 정리된 위키 페이지를 저장합니다.
- `daily/`: 날짜별 메모와 임시 기록을 저장합니다.
- `archive/`: 더 이상 활발히 참조하지 않는 자료를 옮겨 둡니다.
- `log.md`: 수집, 수정, 점검 작업 기록을 남깁니다.

## 위키 페이지 작성 규칙

- 한 페이지는 하나의 주제만 다룹니다.
- 원본 자료에서 온 내용은 어느 파일을 근거로 삼았는지 적습니다.
- 추측과 사실을 섞지 않습니다.
- 서로 관련된 페이지는 위키 링크 형식으로 연결합니다.

## 새 소스가 들어오면

1. `sources/` 폴더의 새 파일을 확인합니다.
2. 자료의 핵심 내용을 한 단락으로 요약합니다.
3. 추출할 만한 인물, 조직, 개념, 주장, 결정 사항을 나눕니다.
4. 필요한 위키 페이지를 만들거나 기존 페이지를 업데이트합니다.
5. `log.md`에 무엇을 읽고 무엇을 바꿨는지 남깁니다.

## 질문에 답할 때

- 먼저 `wiki/`의 정리된 내용을 확인합니다.
- 답변에 필요한 근거가 부족하면 `sources/`를 확인합니다.
- 근거가 부족한 내용은 부족하다고 말하고, 더 넣으면 좋은 자료를 제안합니다.

## 점검할 때

- 중복 페이지, 끊어진 링크, 출처 없는 주장, 오래된 내용을 찾습니다.
- 바로 고치기보다 먼저 점검 결과를 보고하고, 사용자가 승인한 항목만 수정합니다.

## 하지 말 것

- `sources/`의 원본 자료를 임의로 덮어쓰지 않습니다.
- 개인 정보나 회사 기밀을 공개 저장소에 올리라고 제안하지 않습니다.
- 근거 없는 내용을 사실처럼 확정하지 않습니다.
