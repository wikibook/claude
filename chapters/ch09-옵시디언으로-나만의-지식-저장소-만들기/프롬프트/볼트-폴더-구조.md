# 예제 9.1 볼트 기본 폴더 구조 만들기

```
지금 작업 폴더로 지정한 이 볼트를 지식 저장소로 쓸 예정입니다. 기본 폴더 구조를 만들어주세요.

- sources/ : 원본 자료. (기사, 논문, 회의록 등) 나중에 주제별 하위 폴더로 나눌 예정이니 지금은 폴더만 만들어주세요.
- wiki/ : 정리된 위키 페이지. 인물, 개념, 주제별 정리가 들어갑니다.
- daily/ : 날짜별 메모. 매일의 기록이 쌓일 곳입니다.
- archive/ : 오래되었거나 더 이상 참조하지 않는 자료를 옮겨둘 곳입니다.

각 폴더 안에 README.md를 하나씩 만들고, 그 폴더의 용도를 한 줄로 적어주세요. 볼트 최상위에는 빈 index.md와 log.md도 함께 만들어주세요. 각각 위키 색인과 작업 기록으로 사용할 파일입니다.
```
