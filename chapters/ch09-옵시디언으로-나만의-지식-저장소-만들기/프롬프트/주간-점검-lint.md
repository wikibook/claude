# 예제 9.6 주간 점검 프롬프트

```
이번 주에 추가되거나 수정된 위키 페이지를 점검해주세요. 다음 항목을 확인한 뒤, 바로 수정하지 말고 보고서 형태로 먼저 제안해주세요.

1. 서로 내용이 겹치는 페이지
2. 다른 페이지에서 링크되지 않은 페이지
3. 너무 길어서 분리하면 좋은 페이지
4. 최신 소스와 맞지 않는 오래된 주장
5. 민감한 정보가 포함됐을 가능성이 있는 파일
6. 추가하면 좋은 위키 링크
7. 원본 자료에는 있지만 위키에 반영되지 않은 중요한 내용
8. 여러 답변에서 반복되어 굳어진 해석이나 검토가 필요한 주장

결과는 우선순위가 높은 항목부터 정리하고, 실제 파일 수정은 제 확인을 받은 뒤 진행해주세요.
```
