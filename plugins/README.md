# 플러그인 목록

> 책 6장과 연결되는 보충 자료입니다.
> 클로드 코드 플러그인은 특정 작업 환경이나 외부 서비스를 클로드 코드와 연결해 줍니다.

## 설치 기본 흐름

클로드 코드에서 플러그인 페이지를 열고 안내에 따라 `/install` 명령을 실행합니다.
조직 계정이나 회사 장비에서는 설치 전 권한과 보안 정책을 확인하세요. 처음에는 **지금 하는 일에 바로
도움이 되는 하나**로 시작하고, 필요해질 때 하나씩 추가하는 편이 좋습니다.

- **[claude.com/plugins](https://claude.com/plugins)** — 공식 플러그인을 한눈에 볼 수 있는 허브. 여기서 먼저 둘러보세요.

## 클로드 코드 공식 플러그인

작업 흐름을 강화하는 종합 플러그인부터 시작해, 필요에 따라 특정 서비스·작업용 플러그인을 더합니다.

- **[Superpowers](https://claude.com/plugins/superpowers)** — 개발 워크플로우 전반을 강화하는 종합 플러그인.
- **[Frontend Design](https://claude.com/plugins/frontend-design)** — UI/UX 디자인과 프론트엔드 개발에 특화.
- **[Feature Dev](https://claude.com/plugins/feature-dev)** — 기능 개발 전 과정을 보조.
- **[Code Review](https://claude.com/plugins/code-review)** — 코드 리뷰 흐름을 자동화하고 검토 품질을 높임.
- **[Plugin Developer Toolkit](https://claude.com/plugins/plugin-dev)** — 플러그인을 직접 만들 때 쓰는 도구.
- **[Context7](https://claude.com/plugins/context7)** — 최신 라이브러리 문서를 작업 맥락에 주입.
- **[GitHub](https://claude.com/plugins/github)** · **[Slack](https://claude.com/plugins/slack)** — GitHub 저장소·이슈·PR, 슬랙 워크스페이스를 작업 흐름에 연결.
- **[Vercel](https://claude.com/plugins/vercel)** · **[Mintlify](https://claude.com/plugins/mintlify)** — Vercel 배포·프로젝트 관리, 문서 생성·관리 보조.
- **[Sentry](https://claude.com/plugins/sentry)** — 에러 모니터링 정보를 작업 흐름에 연결.
- **[Security Guidance](https://claude.com/plugins/security-guidance)** — 보안 취약점 분석과 보안 판단 지원.
- **[Commit Commands](https://claude.com/plugins/commit-commands)** — Git 커밋 메시지·커밋 작업 보조.
- **[Playwright](https://claude.com/plugins/playwright)** — 브라우저 자동화 테스트를 작업에 연결.

## 관련 저장소

- **[anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins)** — 생산성·영업·마케팅·데이터 작업용 플러그인 예시를 확인할 수 있는 앤트로픽 저장소.
