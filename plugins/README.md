# 플러그인 목록

> 책 7장과 연결되는 보충 자료입니다.
> Claude Code 플러그인은 특정 작업 환경이나 외부 서비스를 Claude Code와 연결해 줍니다.

## 설치 기본 흐름

Claude Code에서 플러그인 페이지를 열고 안내에 따라 `/install` 명령을 실행합니다.
조직 계정이나 회사 장비에서는 설치 전 권한과 보안 정책을 확인하세요.
