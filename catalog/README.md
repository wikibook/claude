# 스킬·플러그인 카탈로그

> 책 4장(스킬)과 6장(플러그인) 보충 자료입니다.

## 스킬과 플러그인 구분

| | 스킬 | 플러그인 |
| --- | --- | --- |
| 하는 일 | 작업 방식·절차·지식 추가 | 스킬 + 슬래시 명령 + MCP를 묶은 확장 |
| 주 설치 | `npx skills add`, 스킬 업로드 | 코워크 UI, `claude plugin install` |
| 책 연결 | 4장 | 6장 |

플러그인 안에도 스킬이 포함됩니다. 코워크 업무 플러그인(Marketing, Sales 등)과 클로드 코드 플러그인은 설치 위치와 용도가 다릅니다.
