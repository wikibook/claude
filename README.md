# 클로드 활용 입문서 보충 자료

이 저장소는 『클로드 활용 입문서』 독자를 위한 보충 자료 허브입니다.
책의 각 장에서 다룬 주제를 더 살펴볼 수 있도록 공식 문서, 참고 링크, 스킬과 플러그인 자료를 모았습니다.

별도 설치 없이 아래 링크에서 필요한 자료를 바로 확인할 수 있습니다.

## 이용 순서

1. 책을 읽는 중이라면 먼저 해당 장의 보충 자료를 확인합니다.
2. 기능이나 용어를 다시 확인하고 싶다면 `resources/`의 공식 문서 링크와 용어집을 봅니다.
3. 스킬이나 플러그인 예시가 필요하다면 `skills/`, `plugins/` 문서를 참고합니다.
4. 내용 오류나 보완이 필요한 부분은 정오표와 변경 내역을 통해 확인합니다.

## 참고

- 책의 본문 설명을 우선 기준으로 삼고, 이 저장소의 자료는 실습과 추가 확인을 돕는 보조 자료로 활용하세요.
- 외부 서비스 화면, 요금제, 기능 이름은 서비스 제공사의 정책에 따라 달라질 수 있습니다.
- 링크가 열리지 않거나 설명과 실제 화면이 다르면 최신 공식 문서를 함께 확인하세요.
