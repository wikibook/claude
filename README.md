# 클로드 활용 입문서

<!-- 표지 이미지 추가 예정 -->

이 저장소는 『클로드 활용 입문서』(위키북스) 독자를 위한 **보충 자료 허브**입니다.  
책에 다 담지 못한 스킬 파일, 플러그인 안내, 외부 링크, 정오표를 한곳에 모았으며  
클로드 기능 변화에 맞춰 지속적으로 업데이트합니다.

별도 설치 없이 아래 링크에서 필요한 자료를 바로 확인할 수 있습니다.
