# 클로드 활용 입문서

> 『클로드 활용 입문서』(위키북스) 독자를 위한 **보충 자료 허브**입니다.

책 실습에 쓰는 **프롬프트**, 스킬 파일, `CLAUDE.md` 예시, 체크리스트와
외부 링크·플러그인 안내를 장별로 정리했습니다.
각 장 폴더에는 책 흐름에 맞춘 링크와 바로 받아 쓸 수 있는 실습 자산이 함께 들어 있습니다.

## 빠른 시작

| 순서 | 할 일 | 링크 |
| --- | --- | --- |
| 1 | 가입·설치·요금제 확인 | [시작하기](resources/시작하기.md) |
| 2 | 지금 읽는 장의 실습 자료 열기 | 아래 [장별 보충 자료](#장별-보충-자료) |
| 3 | 용어·막힘·심화 자료 찾기 | [용어집](resources/용어집.md) · [FAQ](resources/faq-문제해결.md) · [추천 자료](resources/추천자료.md) |

각 장 `README.md`에는 책의 절·예제와 연결되는 파일, 실행 방법, 함께 보면 좋은 공식 문서를 정리했습니다.

## 저장소 구조

```
chapters/    장별 실습 자산 (프롬프트, 스킬, 예제)
catalog/     스킬·플러그인 탐색·설치 가이드
resources/   시작하기, 템플릿, 용어집, FAQ 등 공통 자료
assets/      README 표지 이미지
```
