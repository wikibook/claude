# 클로드 활용 입문서

이 저장소는 『클로드 활용 입문서』(위키북스) 독자를 위한 **보충 자료 허브**입니다.  
책 실습에 쓰는 **프롬프트**, 스킬 파일, `CLAUDE.md` 예시, 체크리스트와
외부 링크·플러그인 안내를 장별로 정리했습니다.

처음이라면 [시작하기 — 가입·설치 링크 모음](resources/시작하기.md)부터 확인하세요.
각 장 폴더에는 책 흐름에 맞춘 링크(README)와 바로 받아 쓸 수 있는 실습 자산이 함께 들어 있습니다.

## 이 저장소를 쓰는 방법

책을 읽다가 실습 파일이나 참고 링크가 필요하면 해당 장 폴더로 이동하세요.
각 장의 `README.md`에는 책의 절·예제와 연결되는 파일, 실행 방법, 함께 보면 좋은 공식 문서를 정리했습니다.

- 프롬프트 예제는 `.md` 파일을 열어 책의 [IN] 요청과 비교하며 클로드에 붙여 넣습니다.
- `SKILL.md`, `CLAUDE.md`처럼 설정 예시는 해당 파일을 본인 프로젝트·볼트에 복사해 씁니다.
- HTML·CSS·JS 실행 파일이나 옵시디언 볼트 전체는 제공하지 않습니다. 결과물은 클로드에서 직접 만듭니다.
- 책 본문에 넣을 짧은 참조 문구는 [책 본문 ↔ 저장소 참조 경로](docs/책-참조-경로.md)에 모아 두었습니다.

> 공개 저장소에는 독자가 재현할 수 있는 정제된 자료만 둡니다.
> 원고 초안, 내부 작업 로그, 개인 정보나 회사 정보가 들어갈 수 있는 자료는 포함하지 않습니다.
