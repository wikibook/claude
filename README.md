# 클로드 활용 입문서

<!-- 표지 이미지 추가 예정 -->

이 저장소는 『클로드 활용 입문서』(위키북스) 독자를 위한 **보충 자료 허브**입니다.  
책에서 만든 **실습 산출물**(아티팩트, 스킬 파일, CLAUDE.md, 옵시디언 볼트 등)과
외부 링크, 플러그인 안내를 장별로 정리했습니다.

처음이라면 [시작하기 — 가입·설치 링크 모음](resources/시작하기.md)부터 확인하세요.
각 장 폴더에는 책 흐름에 맞춘 링크(README)와 바로 받아 쓸 수 있는 실습 자산이 함께 들어 있습니다.

## 장별 보충 자료

책을 읽다가 필요한 장의 자료를 바로 찾을 수 있도록 장별로 정리했습니다.

각 장의 보충자료 양은 책 내용과 최신 기능 변화에 따라 다를 수 있습니다.

| 장 | 제목 | 주요 보충자료 | 링크 |
| --- | --- | --- | --- |
| 1장 | 클로드와 일하는 시대 | 클로드 기본 개념, 모델, 앤트로픽 연구 자료 | [바로가기](chapters/ch01-클로드-기초/README.md) |
| 2장 | 클로드와 대화하는 기술 | 프롬프트 작성 가이드와 튜토리얼 | [바로가기](chapters/ch02-프롬프트/README.md) |
| 3장 | 업무 활용 사례 카탈로그: 클로드를 어디에 쓸 것인가 | 업무 활용 사례 프롬프트 모음 | [바로가기](chapters/ch03-시나리오/README.md) |
| 4장 | 아티팩트, 코드 없이 도구 만들기 | **실습 아티팩트 3종(바로 실행)**, 공유 방법 | [바로가기](chapters/ch04-아티팩트/README.md) |
| 5장 | 스킬, 클로드에게 전문 능력 부여하기 | 스킬 문서, 공식 저장소, **실습 스킬 파일** | [바로가기](chapters/ch05-스킬/README.md) |
| 6장 | 커넥터와 MCP로 클로드를 내 업무에 연결하기 | MCP 공식 문서, 용도별 참조 서버, 디렉터리 | [바로가기](chapters/ch06-커넥터-mcp/README.md) |
| 7장 | 코워크, 함께 일하는 클로드 | 클로드 코드 플러그인과 실전 활용 사례 | [바로가기](chapters/ch07-코워크/README.md) |
| 8장 | 클로드 코드로 한 단계 더 강력하게 | **포트폴리오·칸반 보드·CLAUDE.md 예제**, 공식 문서 | [바로가기](chapters/ch08-클로드코드/README.md) |
| 9장 | 클로드 디자인, 시각 자료 만들기 | **디자인 시스템 예제**, 디자인 도구 링크 | [바로가기](chapters/ch09-디자인/README.md) |
| 10장 | 옵시디언으로 나만의 지식 저장소 만들기 | **볼트 템플릿(CLAUDE.md·폴더 구조)**, 추천 플러그인 | [바로가기](chapters/ch10-옵시디언/README.md) |
