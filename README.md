# 클로드 활용 입문서

<!-- 표지 이미지 추가 예정 -->

이 저장소는 『클로드 활용 입문서』(위키북스) 독자를 위한 **보충 자료 허브**입니다.  
책에 다 담지 못한 스킬 파일, 플러그인 안내, 외부 링크 등을 한곳에 모았습니다.

별도 설치 없이 아래 링크에서 필요한 자료를 바로 확인할 수 있습니다.

## 장별 보충 자료

책을 읽다가 필요한 장의 자료를 바로 찾을 수 있도록 장별로 정리했습니다.

각 장의 보충자료 양은 책 내용과 최신 기능 변화에 따라 다를 수 있습니다.

| 장 | 제목 | 주요 보충자료 | 링크 |
| --- | --- | --- | --- |
| 1장 | 클로드와 일하는 시대 | 클로드 기본 개념, 모델, 앤트로픽 연구 자료 | [바로가기](chapters/ch01.md) |
| 2장 | 클로드와 대화하는 기술 | 프롬프트 작성 가이드와 튜토리얼 | [바로가기](chapters/ch02.md) |
| 3장 | 직장인 시나리오 카탈로그 | 업무 활용 사례와 관련 업데이트 | [바로가기](chapters/ch03.md) |
| 4장 | 아티팩트, 코드 없이 도구 만들기 | 아티팩트 활용 예시와 참고 자료 | [바로가기](chapters/ch04.md) |
| 5장 | 스킬, 클로드에게 전문 능력 부여하기 | 클로드 스킬 문서, 공식 저장소, 커뮤니티 스킬 | [바로가기](chapters/ch05.md) |
| 6장 | 커넥터·MCP, 외부 도구 연결하기 | MCP 공식 문서, 참조 서버, 커뮤니티 레지스트리 | [바로가기](chapters/ch06.md) |
| 7장 | 코워크, 함께 일하는 클로드 | 클로드 코드 플러그인과 실전 활용 사례 | [바로가기](chapters/ch07.md) |
| 8장 | 클로드 코드, 한 단계 더 강력하게 | 클로드 코드 문서, 자동화, 개발 워크플로우 자료 | [바로가기](chapters/ch08.md) |
| 9장 | 클로드 디자인, 시각 자료 만들기 | 디자인 기능, 시각 자료 제작 참고 링크 | [바로가기](chapters/ch09.md) |
| 10장 | 옵시디언으로 나만의 지식 저장소 만들기 | 옵시디언 기본 자료, 추천 플러그인, 클로드 연계 예시 | [바로가기](chapters/ch10.md) |
